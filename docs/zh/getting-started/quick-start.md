# 快速开始

> v1.1.11
> 2026-10

按下面的步骤完成第一次本地对话。

---

## 第一步：启动应用

1. 安装 Windows 包（NSIS x64 或 MSIX Lite），双击启动。其它桌面的构建目标不是本文的正式路径。当前文件见[下载页](https://www.modxai.net/zh/download)。
2. 在欢迎页选择「开始使用」。首次环境安装可跳过。只用 llama.cpp 文本对话时，可以先不装环境。
3. 若安装目录需要管理员权限（例如 `C:\Program Files`），以管理员身份启动。否则应用无法启动。

首次启动会联网拉取初始化数据，仅此一次。失败时检查网络，然后重新启动。

主页面可在已打开的页面之间前后返回。

---

## 第二步：获取模型

首次使用需要导入或下载一个聊天模型。

### 方式一：在线下载（推荐）

1. 点击左侧导航栏的 **「模型库」**
2. 点击顶部工具栏的 **「下载」** 按钮
3. 选择下载源（中国内地用户推荐选择 **ModelScope**）
4. 在聊天模型分类中选择一个模型（如 Qwen3.5-9B-GGUF）
5. 选择量化版本（推荐 Q4_K_M，平衡效果与资源占用）
6. 点击 **「开始下载」**，等待下载完成

> 💡 模型文件较大，下载时间取决于网络速度。

### 方式二：本地导入

如已有本地模型文件（.gguf 格式）：

1. 点击 **「模型库」** → **「导入」**
2. 选择模型文件
3. 确认导入信息并完成

---

## 第三步：加载模型

1. 在模型库的 **「聊天模型」** 标签页中
2. 勾选刚下载/导入的模型
3. 点击顶部的 **「加载」** 按钮
4. 等待模型加载完成（状态变为"已加载"）

---

## 第四步：开始对话

1. 点击左侧导航栏的 **「对话」**
2. 点击 **「新建对话」** 或 **直接输入问题**
3. 在输入框中输入您的问题
4. 按 **Enter** 或点击发送按钮

🎉 恭喜！您已成功完成首次 AI 对话！

## 常见问题

### 模型下载很慢？

- 尝试切换下载源（Hugging Face ↔ ModelScope）
- 检查网络连接

### 模型加载失败？

- 检查系统内存是否充足
- 尝试选择更小的量化版本（如 Q2_K）

### 对话没有响应？

- 确认模型已成功加载（状态显示"已加载"）
- 检查页面底部的系统资源监控
