# 简介

> v1.1.11
> 2026-10

## ModxAI Studio 是什么？

ModxAI Studio 在一个桌面应用里运行本地模型、智能体、图像生成、知识库、数据处理和 LoRA 训练。模型和对话默认留在本机。

智能体按本地小模型设计。1B–3B 参数、32K 上下文可以完成日常多步任务。使用在线模型时，按该服务商的计费和条款执行。

---

## 核心功能

### 🧠 自主智能体

智能体拆分任务、调用工具并报告进度。

- **任务执行**：自动分解步骤，逐步执行，并在界面上显示进度
- **工具与 Skill**：覆盖网页浏览、本地文件读写和终端命令，并可挂载外部 Skill。子任务交给当前任务里已配置的其他角色，不是单独的多智能体产品
- **记忆**：可查看、编辑并导出记忆，再用于后续微调

### 🤖 AI 对话

与本地大语言模型进行智能对话：

- **文本对话**：日常问答、代码生成、创意写作等
- **多模态对话**：支持图文理解，上传图片让 AI 识别分析
- **RAG 增强**：基于您的知识库回答问题，AI 更懂您的领域
- **数据收藏**：收藏优质对话用于生成训练或RAG数据

### 🖼️ 图像与视频生成

使用 Stable Diffusion 模型进行创意生成：

- **文生图**：根据文字描述生成精美图像
- **图生图**：基于现有图片进行风格转换或内容修改
- **视频生成**：支持 Wan 系列等视频生成模型

### 🎤 TTS 语音合成

使用本地 TTS 模型进行文本转语音：

- **中英双语**：支持中文和英文文本的语音合成
- **多音色选择**：提供多种预设音色供选择
- **语速调节**：可调整语音播放速度
- **自动语言检测**：根据输入文本自动识别语言

### 📚 模型库管理

统一管理各类 AI 模型：

- **多模型支持**：聊天模型、多模态模型、HF、向量模型、重排模型、SD 模型、TTS 模型、STT 模型
- **一键下载**：从 Hugging Face 或 ModelScope 直接下载热门模型
- **本地导入**：支持 GGUF、SafeTensors 等多种格式
- **LoRA 适配**：为模型加载专属微调适配器
- **局域网服务**：加载后自动暴露 OpenAI 兼容 API，供局域网内其他应用调用
- **在线模型服务**：DeepSeek、OpenRouter，以及 OpenAI 兼容的 Chat Completions 接口。高级参数中还有 OpenAI 与 Claude 的提示词缓存选项

### 📊 数据处理

将原始数据转化为可训练数据集：

- **SFT 数据生成**：从文档、结构化数据等生成监督微调数据
- **RAG 知识库**：构建向量化知识库，支持智能检索
- **音频转文本**：将语音转录为多种结构化文本
- **AI 合成**：通过本地模型按需完成数据分析

### 🎯 模型训练

- **LoRA 高效微调**：仅需 8GB 显存即可开始训练
- **实时监控**：可视化训练进度和损失曲线
- **检查点评估**：自动评估多个检查点，推荐最优结果
- **一键导出**：将训练成果导出为 GGUF 格式，直接用于推理
- **记忆训练**：基于智能体主动积累或与用户手动收藏的对话记忆，自动迭代优化专属模型

### 🗂️ 记忆、定时任务与频道

- **记忆管理**：查看、修改、归档智能体记忆和手动收藏，并导出为训练或知识库数据
- **定时任务**：按间隔、固定时间或上游任务完成情况，自动执行智能体任务、记忆整理、记忆微调和知识库更新
- **外部访问**：通过 Telegram、Discord、钉钉、飞书机器人访问本机智能体，也可让本机或局域网程序调用网关的 HTTP API。未配对的聊天来源不能下发任务

### ⚙️ 零门槛环境配置

告别复杂的环境配置：

- **首次运行引导**：第一次启动会提示完成上手步骤，并引导安装环境
- **一键安装**：自动检测硬件，推荐最佳配置
- **按需选择**：支持全部/智能体/语音合成三种安装能力，按需安装
- **沙箱隔离**：独立环境，不影响系统其他软件
- **按需加载**：功能未使用时不加载依赖

## 为什么选择 ModxAI Studio？

| 优势 | 说明 |
|------|------|
| **本地推理** | 模型、数据集、对话和记忆默认留在本机并加密存储。在线 API 可选，并按服务商计费 |
| **小模型可执行任务** | 智能体面向 1B–7B、32K 上下文的本地模型 |
| **一条工作流** | 数据处理、训练、推理、记忆和定时任务在同一应用内 |
| **参数可改** | 角色、工具、上下文长度和推理参数可在界面中调整 |
| **沙箱** | 便携 Python 环境与智能体工具独立于系统 Python |
| **图形界面** | 主路径不需要 Docker、系统 Python 或命令行 |
| **记忆可再训练** | 可导出记忆，再用于记忆微调 |

## 系统要求

### 最低配置

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11（64 位）。正式安装包是 NSIS x64，另有 MSIX Lite |
| 内存 | 16GB RAM |
| 存储 | 20GB 可用空间 |
| 处理器 | 支持 AVX2 指令集 |

### 推荐配置

| 项目 | 要求 |
|------|------|
| 内存 | 32GB+ RAM |
| 显卡 | NVIDIA RTX 系列 (8GB+ 显存) |
| 存储 | SSD 固态硬盘 |

> 💡 无 GPU 也可使用 CPU 模式运行，适合入门体验。

下面的步骤、路径和显卡说明按 **Windows** 正式安装包来写。打包脚本另有 arm64 macOS DMG，以及 arm64 Linux 的 AppImage 和 deb。它们不是正式发布。Intel Mac 和 Linux x64 不在这条产品路径上。arm64 macOS 上，环境检查把统一内存 GPU 记为信息项，Python 依赖走 CPU 环境，推理走 Metal。当前能下载的文件见 [下载页](https://www.modxai.net/zh/download)。
