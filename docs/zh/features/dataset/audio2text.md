# 音频转文本

> v1.1.11
> 2026-11

将本地音频文件批量转成带时间戳的文本，按需生成字幕或便于阅读的文档。适合整理会议录音、访谈和播客，不用于麦克风实时转录。

## 使用前准备

- 在**设置 → 系统**安装所需的 CPU 或 GPU 环境，并确认环境已就绪。操作见[环境配置](../settings/environment.md)。
- 准备 `.mp3`、`.wav`、`.m4a` 或 `.wma` 音频文件，并放入一个输入目录。
- 准备独立的输出目录。处理会包含输入目录的子目录，建议先用少量文件试转录。
- 在模型库中准备一个 **faster-whisper** 模型。保留完整模型文件夹，其中需有 `model.bin`，以及 `vocabulary.json` 或 `tokenizer.json`。不要只下载权重文件。

### 下载模型

1. 打开「模型中心 → 模型下载」。
2. 在「资源浏览」中选择「语音识别」，选择模型、下载源和版本。
3. 确认所需空间及保存位置，开始下载。
4. 在「下载管理」中检查下载和导入结果，再到「模型中心」的「音转文」页确认模型已出现在列表中。

「资源浏览」的下载任务会在文件校验后自动尝试导入模型库。若使用「仓库下载」或自行下载，需手动导入：打开「模型中心 → 音转文」，点击「导入」，选择模型文件夹中的 `model.bin`，检查名称与分类后完成导入。

下载需要联网。模型大小以下载页面为准；所需内存、显存和转录速度会随模型、音频和设备变化。

## 操作步骤

1. 打开「自我改进 → 数据」，选择「MM → 音频转文本」。
2. 在「输入目录」选择或填写音频所在目录，在「输出目录」设置结果保存位置。
3. 在「文件类型」保留「所有支持类型」，或只勾选本次要处理的扩展名。
4. 在「音频转文本模型」中选择已导入的 faster-whisper 模型。
5. 保留「模型加载」「转录」「输出」三个步骤。需要调整时，点击对应步骤上的「…」打开参数设置并保存。首次使用可先保持默认值。
6. 点击「开始」，在「进度监控」中查看文件数量、进度和日志。应用会扫描输入目录及其子目录，按文件修改时间从新到旧逐个处理。
7. 处理结束后查看完成或错误提示。成功提示中的「打开输出目录」可打开结果文件夹。

如果模型刚导入但还未出现在选择列表中，可离开数据页后重新进入，再选择模型。

## 确认结果

结果保存在指定的输出目录，以音频文件名去掉扩展名后命名。例如，`meeting.mp3` 对应 `meeting.json`。

| 格式 | 用途 |
| --- | --- |
| JSON | 每个处理完成的音频都会生成。包含识别文本、片段起止时间和检测到的语言；开启词级时间戳后还会包含相应信息。 |
| SRT | 按需勾选，生成带时间码的字幕。 |
| HTML | 按需勾选，在浏览器中阅读带时间戳的文本。 |
| Markdown（md） | 按需勾选，生成便于继续编辑的文本列表。 |

即使只选择其他输出格式，也会生成 JSON。请抽查文件是否齐全，并校对识别文本和时间戳，尤其是姓名、专有名词和嘈杂片段。

**注意同名覆盖：**所有结果直接写入同一个输出目录，不保留输入子目录结构。不同子目录中的同名音频，或 `meeting.mp3` 与 `meeting.wav`，会写入相同的结果文件名。开始前请改名或分批使用不同输出目录；已有同名结果也可能被覆盖。

## 参数设置

以下是常用参数的初始值。已保存过设置时，以参数面板中当前显示的值为准。

### 模型加载

| 参数 | 初始值 | 说明 |
| --- | --- | --- |
| 计算设备 | `auto` | 可选 `auto`、`cuda`、`cpu`。自动模式会根据设备和运行环境选择；CUDA 不可用时可能改用 CPU。 |
| 计算精度 | `float16` | 可选 `float32`、`float16`、`int8`、`int8_float16`、`int8_float32`。CPU 可使用 `float32`、`int8` 或 `int8_float32`；不兼容的 CPU 精度会调整为 `float32`。 |
| CPU线程数 | `4` | 高级参数，范围 1–32。 |
| 工作进程数 | `1` | 高级参数，范围 1–8。 |
| 设备索引 | `0` | 高级参数，范围 0–7，用于选择 CUDA 设备。 |

若要让新的设备或精度设置用于已经加载的同一模型，先结束任务，到「模型中心 → 音转文」卸载模型，再开始新任务。

### 转录

| 参数 | 初始值 | 说明 |
| --- | --- | --- |
| 搜索束宽 | `5` | 范围 1–10。提高数值会增加解码工作量，不保证结果更准确。 |
| 音频语言 | `auto` | 自动检测，或指定中文、英语、日语、韩语、西班牙语、法语、德语、俄语。 |
| 语音活动检测 | 开启 | 也称 VAD，用于筛选语音片段。若内容漏识别，可关闭后重试。 |
| 词级时间戳 | 关闭 | 高级参数，开启后在 JSON 中保存词级时间信息。 |
| 最小静音时长 | `2000` 毫秒 | 高级参数，范围 100–5000 毫秒，启用 VAD 时使用。 |

### 输出

「输出格式」初始选择为 `json`，可多选 `srt`、`html`、`md`。输出内容与命名规则见[确认结果](#确认结果)。

## 停止与重新处理

- 点击「停止处理」后，等待界面确认停止，再启动下一次任务。停止不一定立即完成。
- 已写出的完整结果会保留；当前音频可能只留下 `.transcribing.json` 临时文件，不能当作完整结果。正常写出最终 JSON 后，应用会尝试删除对应临时文件。
- 不支持从临时文件或中断位置继续转录。重新点击「开始」会重新扫描和处理符合条件的文件，不会自动跳过已完成项。
- 如只需重做失败或未完成的文件，将它们放入单独的输入目录，并使用新的输出目录，避免覆盖已确认的结果。

## 注意事项

- **任务结束不等于模型卸载。**转录完成或在转录中停止后，已加载模型会保留。需要释放资源时，先确认任务结束，再打开「模型中心 → 音转文」，点击「卸载模型」。
- **先检查错误，再判断是否完成。**个别文件失败时，其他文件可能继续处理；请对照日志和输出目录确认需要重做的文件。
- **选择适合设备的设置。**内存或显存不足时，可尝试更小的模型，或切换到 CPU 并使用兼容精度。不要仅凭模型文件大小判断运行时资源是否足够。

## 常见问题

### 模型列表为空或加载失败怎么办？

先在「模型中心 → 音转文」确认已导入模型。检查模型路径是否仍然有效，文件是否下载完整，以及 `model.bin` 与 `vocabulary.json` 或 `tokenizer.json` 是否位于同一文件夹。重新进入数据页后再选择模型。

### 没有找到待处理文件怎么办？

检查输入目录和「文件类型」筛选，确认目录中包含所选扩展名的音频，而不是视频或压缩包。可先用播放器确认音频能够正常播放。

### 转录为空或遗漏较多怎么办？

先确认原音频有清晰语音，并检查所选语言。开启 VAD 时，应用在识别片段过少的情况下会尝试关闭 VAD 重做一次；这不保证补全内容。仍有问题时，可手动关闭 VAD，用单个文件重新尝试并核对结果。
