# 代码分析（CODE）

从本地代码仓库建立可重复使用的分析结果。可以先查看哪些文件解析成功，再按需要导出知识库、预训练语料、SFT 问答或原始数据。

## 分析代码仓库

1. 在 **设置 → 系统 → 环境管理**安装**代码分析**。如果仍提示代码解析资源不可用，请按提示选择**全部(推荐)**安装。如果准备生成 SFT 问答，还需要在模型中心准备本地聊天模型。
2. 打开 **自我改进 → 数据 → CODE → 数据源**。选择源码目录和结果保存目录；建议分开存放。
3. 如需跳过构建目录或生成文件，在**排除文件或目录**中每行添加一条规则，例如 `build/` 或 `*.min.js`。
4. 点击**开始分析**。结束后进入**分析审阅**，检查已解析数量、语言和文件状态。

## 审阅与复用

- 按文件名、语言或状态筛选。双击文件查看源码、解析诊断或已有的数据集生成结果。
- **已排除**表示文件匹配排除规则；**不支持**或**语法错误**不要当作已完整解析。导出前检查重要目录的解析状态。
- 已有分析结果时，在**数据源**选择原保存目录并点击**打开结果**，再选择所需**版本**。源码更新后可使用相同的源码和结果目录继续分析；没有内容变化时，不会生成新版本。

## 导出数据集

在**导出数据集**中选择用途和保存位置：

| 类型 | 用途 |
| --- | --- |
| **知识库** | 生成用于检索的代码分块。点击**用于知识库 (RAG)**，继续配置并建立知识库。 |
| **预训练** | 将解析结果导出为可用于准备预训练的数据。 |
| **SFT** | 选择本地聊天模型生成问答。可填写**补充要求**；生成并导出后，在文件详情中抽查生成结果再用于训练。 |
| **原始数据** | 导出源码与分析结果，供后续处理。 |

导出不会自动开始训练或建立向量索引。进入下一个页面后，核对样本文件或目录、模型和配置，再启动任务。处理私有仓库前，先确认对源码的使用权限，并排除凭据等不应进入数据集的文件。
