# 定时任务

按时间运行智能体、记忆整理、数据处理、模型训练或自我改进。也可以等一个任务成功后，把结果交给另一个任务继续处理。

在主侧栏打开**更多 → 定时任务**。

## 任务类型

| 类型 | 使用前准备 |
| --- | --- |
| **智能体** | 准备主角色模型、工具和任务提示词。使用现有会话时，先检查该会话的配置。 |
| **记忆整理** | 使用本地主模型。可整理最近 24 小时、指定会话或日期范围内的内容。 |
| **数据处理** | 按所选数据类型准备源文件、模型和环境；例如用文本生成训练样本，或更新知识库。 |
| **模型训练** | 准备训练环境和模板，指定训练数据；也可从上游绑定训练文件。记忆微调也在此分类。 |
| **自我改进** | 准备提示词或 Skill 的改进配置、评测任务和所需模型。 |

## 创建与编辑任务

1. 点击**新建任务**，填写名称并选择类型。
2. 填写任务的输入，按需选择**预设**或训练模板。点击旁边的齿轮打开参数设置。选择**仅用于当前任务**不会改写原预设；要在其他任务中重复使用，选择**存为新预设**或**存为新模板**。
3. 在**执行计划**设置触发方式；有依赖时选好**上游来源**。使用计时规则时，检查日期、星期和时间。
4. 保存后检查任务列表中的启用状态和下次运行时间。想先验收结果，可以从列表手动运行一次，再检查运行记录。

编辑现有任务时，重新确认输入和触发条件。停用任务可取消后续触发；要结束已开始的执行，请在运行记录里停止本次运行。

## 调度策略

任务可按间隔或指定时间运行。要等另一个定时任务产生结果，可将其选为上游；仅需依赖触发时选择**仅随上游触发**。

### 上游任务

以「先准备训练数据，再训练模型」为例：

1. 先保存一个**数据处理**任务，让它产出训练数据。
2. 新建**模型训练**任务，在**上游来源**选择**定时任务**和刚保存的任务。选择**仅随上游触发**，并设置在上游成功时运行。
3. 点击**绑定产物**，把**训练数据**对应到**训练文件**；有匹配的验证数据时，可另外绑定**验证文件**。核对训练模板与数据格式，再保存并启用任务。
4. 上游完成后，到下游的**运行历史**核对使用的输入和结果。若缺少必需产物，先检查上游运行，再重试下游。

如果要使用已经完成的一次运行，在相应来源下用**选择记录**选定该次结果；这与等待下一次上游触发不同。界面只列出与目标字段匹配的可选产物。

## 运行历史

选中任务可查看运行状态、触发来源、错误和结果文件。点击**打开**可查看可用的结果；也可从[消息盒子](../agent/inbox.md)回到对应记录。

## 任务执行与停止

- 从任务列表手动执行一次，不必修改周期。
- 从运行记录停止当前执行，不会停用以后按计划触发的运行。要暂停计划，关闭任务的启用开关。
- 定时任务不会并行启动；其他任务正在执行时，请查看运行记录和下次触发时间。

## 注意事项

需要按时执行时，请保持应用和设备运行，并保证所需模型、文件与权限仍可用。使用在线模型或外部工具的任务仍需网络，并可能产生服务商费用。启用无人值守运行前，先检查工具和审批设置，尤其是会修改文件、启动训练或调用外部服务的任务。
