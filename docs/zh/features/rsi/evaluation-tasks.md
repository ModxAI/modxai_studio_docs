# 评测任务与会话导入

> v1.1.11
> 2026-11

评测任务是每轮都要执行的问题或操作。一项 RSI 运行可添加 **1–10 个任务**，也可以从已有聊天或智能体会话导入。

## 手工添加任务

1. 在 **自我改进 → 配置 → 评测任务**找到**自定义任务**。
2. 填写完整的问题、背景和预期要求。使用快捷示例时，补齐示例中的条件和资料。
3. 需要附件时，点击附件入口选择文件，检查已添加的文件名。
4. 点击 **添加任务**。只在输入框中填写文字，还没有加入评测列表。
5. 展开列表中的**输入**，核对消息和附件。需要替换任务时，移除该项后重新添加。

建议选几种有代表性的情况，例如正常问题、资料缺失的问题和容易误判的边界情况。把应遵守的格式、计算条件或资料范围写在任务里，避免只写“回答得更好”。

## 选择附件和执行方式

- **聊天**模式的附件入口提供图片和视频。需要使用能处理对应输入的模型。
- 普通文件和音频任务使用**智能体**模式，并配置所需工具或环境。
- 从会话导入后出现“此任务包含文件或音频，请选择智能体执行”时，切换**任务模式**，再检查智能体配置。
- 请通过附件入口选择文件，不要只把本地文件路径当作附件填写。开始前检查所有文件仍可读取。

使用在线模型时，附件内容可能随模型请求发送给服务提供方。请先移除不适合外发的资料。

## 从聊天导入

1. 点击 **导入会话**，选择 **Chat**。
2. 在**会话标题**中选择会话。
3. 在**回答**中选择要分析的历史回答。
4. 展开**输入预览**，核对该回答之前的用户问题及必要前文。
5. 点击 **确认导入**，返回配置页检查任务和模型。

所选历史回答用于分析案例；每轮仍会重新执行对应输入。它不会作为学生模型应照抄的正确答案。

首次导入聊天任务时，页面可能填入可取得的系统提示词和学生模型。历史不一定保留完整运行参数；看到“原运行参数不可取得”时，按本次需要重新核对模型和参数。

## 从智能体会话导入

1. 点击 **导入会话**，选择 **Agent**。
2. 选择会话，再在**任务描述**中选择具体任务。
3. 检查**输入预览**，点击 **确认导入**。
4. 先确认**任务模式**为**智能体**，再打开学生侧的**配置**，核对模型、工具、审批设置、工作目录和 Skill。

当导入项是列表中的第一个任务时，页面可能带入可取得的智能体配置并切换任务模式；已有其他任务时，请自行确认模式。已经手动设置的配置不会被后续导入自动覆盖。不要假设同一组任务会分别沿用每个来源会话的所有参数。

导入任务可能仍在原会话的工作目录执行，仅修改学生侧工作目录不会将它迁移到测试目录。需要换目录时，重新手工创建任务，选择测试工作目录并检查输入资料，避免改动原目录中的内容。

## 补齐缺失文件

出现 **待补文件**时：

1. 查看列出的文件名。
2. 点击该任务旁的附件按钮 **补充同名输入文件**。
3. 选择对应文件，核对提示已消失。
4. 若多个文件同名且无法确定对应关系，使用不同文件名重新添加任务。

缺失文件未补齐时不能开始。无法恢复历史资料时，可移除该任务，重新填写问题并添加当前可用的附件。

## 运行前检查

- 任务列表中的数量正确，没有把待输入内容误当成已添加任务。
- 每个任务都能独立说明要做什么；需要的文件和权限已准备好。
- 智能体可能反复执行同一操作。涉及发消息、修改数据或调用付费服务时，先使用测试目标并检查审批设置。
