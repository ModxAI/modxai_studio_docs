# RSI 自我改进

> v1.1.11
> 2026-11

RSI 用一组任务反复测试并调整系统提示词或 Skill。运行后，可以对照原始回答、各轮结果和评测依据，选择需要保留的方案。

从左侧导航打开 **自我改进**。页面按 **配置 → 迭代 → 对比 → 导出** 排列。

## 选择改进内容

| 改进内容 | 适合的用途 | 执行方式 |
|---|---|---|
| **提示词** | 调整回答结构、措辞、判断规则或任务处理要求 | **聊天**或**智能体** |
| **Skill** | 调整技能说明和配套文本资料 | **智能体** |
| **两者** | 同时调整系统提示词和 Skill，作为一个方案测试 | **智能体** |

**教师模型**根据目标制定评测标准、提出改法并评价结果。**学生模型**或学生智能体执行任务。两种角色都可以使用界面提供的本地模型或在线连接。

RSI 保存的是提示词和 Skill 文件。需要更新模型权重时，使用[模型训练](../training/overview.md)。

## 完成第一次改进

1. 点击页面右上角的 **新建任务**（加号）。
2. 将 **改进内容**设为**提示词**，**任务模式**设为**聊天**。
3. 选择教师和学生模型。填写**任务名称**、**改进目标**和**系统提示词**。
4. 在**评测任务 → 自定义任务**填写一个有代表性的问题，点击**添加任务**。
5. 确认终止策略，点击右上角的 **开始**（播放图标）。
6. 在**迭代**查看进度。运行结束后，打开**对比**检查回答和评测依据。
7. 打开**导出**，确认所选轮次及正文，再复制或导出文件。

完整设置见[配置与开始运行](./configure.md)。已有真实问题时，可[从会话导入评测任务](./evaluation-tasks.md)。

## 使用前注意

- 一次只能运行一个 RSI 任务。任务数量、迭代轮数、模型速度和工具执行时间都会影响耗时。
- 在线模型会接收本次请求中的内容，并可能按提供方规则计费。多轮改进会多次调用模型。
- 使用智能体时，评测任务会实际调用允许的工具，可能读取、修改文件或访问外部服务。请先检查工作目录、工具权限和自动审批设置，用测试资料运行可能产生副作用的任务。
- 评分来自模型，只反映这组任务和当次评测。采用前核对回答、文件和关键事实，再用未参与改进的任务检查效果。
