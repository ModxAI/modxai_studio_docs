# 改进 Skill

> v1.1.11
> 2026-11

Skill 将任务说明和配套资料放在一个目录中。RSI 可以改进现有 Skill，也可以从新建的说明开始，并通过智能体实际执行任务来检查效果。

## 使用前准备

- 准备可以执行任务的学生智能体配置。
- 在学生主角色中启用工具，并允许使用 **skilltool**。
- 使用现有 Skill 时，确认其目录可读取，并包含有效的 **SKILL.md**。
- 涉及文件修改或外部操作时，准备测试工作目录并核对审批设置。

## 改进现有 Skill

1. 打开 **自我改进 → 新建任务**，将**改进内容**设为 **Skill** 或 **两者**。任务模式会使用**智能体**。
2. 选择教师模型，点击学生侧的**配置**（齿轮）。
3. 核对主角色模型和工具，在配置中指定包含现有 Skill 的根目录。根目录应包含各个 Skill 子目录。
4. 返回配置页，在**起始 Skill**旁点击**刷新 Skill**，从列表选择需要改进的技能。
5. 检查 **SKILL.md** 和各资料文件。可在文件标签中修改文本；此时修改的是本次草稿。
6. 填写任务名称、改进目标和评测任务，再设置终止策略。
7. 点击 **开始**。需要审批或补充输入时，通过 **查看对话**进入本轮智能体会话处理。

选择 **Skill** 时，系统提示词保持固定，只调整 Skill 文本。选择 **两者**时，提示词和 Skill 会作为同一个方案改进；在对应标签中分别核对起始内容。

## 新建 Skill

1. 在**起始 Skill**列表选择 **新建 Skill**。
2. 填写**目录名称**。名称不能为空，不能以点开头，也不能包含 `/`、`\` 或 `:`。
3. 修改生成的 **SKILL.md**，写清什么时候使用这个技能、操作步骤以及需要遵守的条件。保留开头的元信息，确保 `description` 有内容。
4. 需要配套资料时，在文件名输入框填写例如 `guide.md`，点击 **新建资料文件**（加号）。文件会放在 `references` 目录下。
5. 在新文件标签中填写正文。其他资料文件可通过标签上的移除按钮删除；**SKILL.md**不能移除。
6. 添加评测任务并开始运行。

## 哪些内容可以改进

- RSI 可编辑和改进 **SKILL.md** 以及支持的 UTF-8 文本文件：`.md`、`.txt`、`.json`、`.yaml`、`.yml`、`.csv`、`.tsv`。
- **scripts** 和 **assets** 中的内容不参与文本改写。现有脚本和资源随原 Skill 副本保留，导出时一并复制。
- 每轮使用独立的 Skill 副本，迭代不会直接改写原 Skill 目录。智能体执行任务产生的其他文件修改仍然可能发生，请检查工作目录和权限。
- 选择 Skill 后改变根目录，可能使原选择失效。看到来源不一致提示时，恢复原根目录或重新选择 Skill。
- 智能体需要实际加载目标 Skill 才能参与有效比较。若出现“本次未加载目标 Skill”，先查看关联会话和工具配置；已有回答仍可查看，但不能把它当作该 Skill 的有效评测。

## 取用结果

在**对比**和**迭代详情**核对结果后，进入**导出**，选择需要保留的轮次。先导出到新的父目录检查内容，再决定是否替换原 Skill。

导出不会替你把当前智能体切换到新方案。要使用导出的 Skill，在智能体配置中选择其父目录作为 Skill 根目录、刷新列表并勾选该 Skill。组合方案还需要将导出的提示词填入目标角色。

详细步骤见[对比与导出成果](./results.md)。
