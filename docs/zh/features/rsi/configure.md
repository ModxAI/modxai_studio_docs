# 配置与开始运行

> v1.1.11
> 2026-11

为 RSI 选择模型、说明改进目标，再用相同的一组任务测试每轮方案。

## 使用前准备

- 使用本地模型时，先在[模型库](../models/overview.md)下载或导入模型，并准备该模型所需的运行环境。
- 使用在线模型时，先在设置中添加可用的在线连接和凭据。
- 至少准备一个评测任务。需要工具、普通文件或音频输入的任务，选择**智能体**模式。

## 配置任务

1. 打开 **自我改进**，点击 **新建任务**。
2. 选择**改进内容**。首次使用可选**提示词**；Skill 或组合改进见[改进 Skill](./skills.md)。
3. 在**指导与评测**区域选择**教师模型**。本地模型从列表选择；在线模型先选择连接凭据，再选择模型。列表未更新时点击**刷新**。
4. 在**执行与测试**区域选择**任务模式**：
   - **聊天**：直接选择学生模型和参数，适合问答等无需工具的任务。
   - **智能体**：点击旁边的**配置**（齿轮），核对主角色模型、工具、工作目录、Skill 和审批设置。这里设置的是本次 RSI 使用的智能体配置。
5. 填写**任务名称**，便于之后从历史记录查找。
6. 填写**改进目标**，说明要改善的具体问题。例如：“先给结论，再列处理步骤；资料中没有的时间和金额须明确说明未知。”
7. 填写待改进的**系统提示词**。也可展开**快捷输入**后修改示例。聊天模式留空时使用默认系统提示词。
8. [添加或导入评测任务](./evaluation-tasks.md)，确认任务已出现在列表中。
9. 设置**终止策略**，点击右上角的 **开始**。

智能体使用在线教师时，需要勾选 **同意将工具记录与文件内容发送给在线模型评分**。请确认任务资料可以发送给所选服务；学生智能体自身的在线模型和外部工具也可能传送其处理的内容。

## 设置终止策略

| 设置 | 含义 |
|---|---|
| **最大迭代轮数** | 可设 1–10，默认 3。运行还会先执行一次原始基线，因此最多有“基线 + 所设轮数”组结果。 |
| **目标分数** | 可设 0–100。最佳轮的任务平均分达到此值即停止，原始基线也可能触发。留空不启用。 |
| **最低分数** | 可设 0–100。某个改进轮的任务平均分低于此值即停止；原始基线不检查。留空不启用。 |

目标分数和最低分数是停止条件，不是对结果正确性的保证。首次尝试可少设几轮，检查任务和评测标准是否合适。

## 调整模型参数

选择模型后，按需要展开**模型参数**。可用选项随模型类型变化。

| 参数 | 使用说明 |
|---|---|
| **上下文长度** | 留空沿用模型设置；0 使用模型上下文上限。过小可能无法容纳任务、资料和评分依据。 |
| **最大输出长度** | 0 使用自动输出预算。需要更长回答时可调整，但也要为输入内容留出上下文空间。 |
| **随机性**、**Top P**、**Top K**、**Min P**、**重复惩罚** | 控制生成方式。先沿用默认值，再按任务调整；参数变化会影响比较条件。 |
| **思考深度** | 按模型支持情况选择。更深的思考可能增加耗时和在线费用。 |
| **LoRA** | 在适用的本地模型上选择已有适配器。 |
| **运行设备**、**精度**、**模型任务** | 仅在对应模型类型支持时设置，按模型和本机环境选择。 |

## 查看运行进度

开始后进入**迭代**。页面显示状态、耗时和当前阶段，包括制定标准、执行基线、基线评分和迭代改进。展开**评测标准**可以查看本次使用的要求；在**迭代详情**按轮次查看各项任务的回答。

智能体等待审批或输入时，点击 **查看对话**，在关联会话处理后返回 RSI。不要因为页面停留在某个阶段就重复开始任务。

需要结束时点击 **停止运行**，等待状态变为**已停止**。正在停止期间不能开始另一项 RSI 任务。停止不会撤销已经完成的文件修改或外部操作。

运行后的配置供查看。若要修改模型、目标、任务或轮数，使用**继续改进**或**新建任务**创建新的配置，见[历史与异常处理](./history.md)。
