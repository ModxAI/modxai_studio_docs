# 对比与导出成果

> v1.1.11
> 2026-11

查看每轮修改、回答和评测依据，选择需要保留的提示词或 Skill。可以采用推荐方案，也可以导出其他已有轮次。

## 检查结果

1. 打开 **自我改进 → 对比**，或从**历史记录**打开一项运行。
2. 选择**原始基线**或具体轮次，查看**本轮优化策略**。
3. 提示词或组合改进可点击 **展开**，并排查看基线提示词和所选轮次提示词。
4. 阅读**效果对比**中的回答，以及**评测报告**中的**提升亮点**、**待优化项**和**评测依据**。
5. 有多个评测任务时，回到 **迭代 → 迭代详情**，按轮次检查各项任务的回答。智能体任务可通过 **查看对话**核对实际操作和产出。
6. 对重要结论、计算和文件内容自行复核，再决定保留哪个版本。

## 理解评分和推荐

- 原始基线是开始改进前的方案。教师先制定一组评测标准，再对结果评分。
- 轮次分数为任务平均分，范围是 0–100。未完成有效评测的内容不能当作已验证方案。
- **评分曲线**中的历史最高评分与推荐方案不是同一含义。推荐还会考虑候选与参照方案在同一次评测中的表现，不要只按曲线最高点选结果。
- 推荐可能仍是原始基线，表示此次没有选出更好的方案。增加轮数也不保证提升。
- 出现“评分依据已节选”时，模型只看到部分依据。出现“未完成有效比较”时，可查看已有内容，但需要另行验证。
- 修改模型、参数、任务、资料或环境后，分数不宜直接用于前后排名。

## 复制或导出

运行中或正在停止时，先等待任务结束。

1. 打开 **导出**。
2. 在轮次列表中选择需要的版本。**对比**与**导出**共用当前所选轮次；浏览其他轮次后，导出前再确认一次。
3. 检查正文。需要时可直接修改提示词或 Skill 的已有文本文件。
4. 点击 **复制**可复制当前提示词，或 Skill 当前文件标签中的内容。
5. 要保存文件，点击 **导出**，在系统对话框中选择保存位置。
6. 若出现 **覆盖同名文件？**，检查列出的文件，确认后点击 **覆盖文件**。不确定时取消并改用新目录。
7. 等待 **已导出**提示，再检查所选目录。

| 改进内容 | 保存到所选目录的内容 |
|---|---|
| 提示词 | `prompt.txt` |
| Skill | 以 Skill 目录名称命名的子目录，包含 `SKILL.md`、资料和保留的原始资源 |
| 两者 | `prompt.txt` 和 Skill 子目录 |

选择的是**父目录**。例如 Skill 名称为 `support-guide`，选择 `D:\RSI-exports` 后，Skill 保存到其中的 `support-guide` 子目录。请勿重复选择同名 Skill 子目录，造成额外嵌套。

## 编辑和覆盖的注意事项

- 编辑后显示**已修改**。原来的评分对应运行时版本，不代表手工修改后的内容已被重新评测。
- 导出页可以修改或移除已有资料文本，但不能新增资料文件或重命名 Skill。新增资料文件请在配置草稿中处理；只有新建 Skill 可以编辑目录名称。
- 保存只写入此次导出的文件，不会清空目标目录。导出到已有目录时，未包含在新方案里的旧文件可能仍然存在；要获得清晰的新版本，优先使用空目录。
- 如果提示文件或正文已变化，请重新检查目标目录和当前正文，再发起导出。
- 目录保存需要桌面端的系统目录选择器。若页面提示当前环境不支持，使用桌面端导出；仍可复制当前文本。

## 在其他功能中使用

- **提示词**：复制到目标聊天的系统提示词，或智能体目标角色的系统提示词设置中。
- **Skill**：在智能体配置中选择导出目录作为 Skill 根目录，刷新并勾选该 Skill。
- **两者**：同时应用提示词和 Skill，再用实际任务检查效果。

文件导出成功不代表当前聊天或智能体已自动切换。若提示“文件已保存，请在智能体配置中刷新 Skill”，先确认文件，再刷新列表，不必因为刷新失败而重复覆盖文件。
