# 历史、继续改进与异常处理

> v1.1.11
> 2026-11

通过历史记录回看结果、准备下一次改进，或处理停止和失败的运行。

## 查找历史记录

1. 打开 **自我改进**，点击右上角的 **历史记录**（时钟图标）。
2. 按**改进内容**筛选，或在**搜索标题**中查找任务名称。
3. 点击记录查看状态、轮次和结果。需要更多记录时点击 **加载更多**。

运行中仍可查看其他记录。页面顶部的停止按钮针对当前正在运行的任务；悬停可查看任务名称，需要时使用 **查看运行进度**返回。

## 继续改进与新建任务

**继续改进**用于从已有结果准备新的运行：

1. 打开已有结果的历史记录，点击 **继续改进**；执行异常的记录也可能在 **更多操作**中提供此入口。
2. 核对带入的目标、模型、任务、提示词和 Skill，可按需要调整。
3. 点击 **开始**，创建新的运行。原记录保留。

继续改进优先采用系统选出的最佳方案；没有有效最佳方案时，可能采用已有候选。它不采用你在对比页随意选中的另一轮，也不会自动带入导出页的手工编辑。请在新配置中检查并补上需要的内容。

尚无可继续使用的候选、仅有初始方案，或另有 RSI 任务正在运行时，不能继续改进。若要从空白配置开始，点击 **新建任务**。新建会清空当前配置草稿，已有历史记录不受影响。

## 查看改进笔记

**对比 → 改进笔记**可查看本次整理的经验及本次参考的既有经验，包括观察结果、适用条件和无效尝试。引用的笔记可通过 **查看来源**返回原记录。

一项**已完成**的运行，将未经手工修改的**最佳方案**成功导出到目录后，会标记**已采用**。若原始基线和至少一个候选都有有效比较，系统会整理改进笔记。

- 只复制文本、导出其他轮次或保存手工修改后的内容，不会因此标记该最佳方案已采用。
- 笔记整理失败不影响已保存的文件。在笔记区域点击 **重试**即可；出现 **整理笔记**时也可手动发起。
- 后续通过**继续改进**创建的运行可参考这一系列已采用结果的笔记。新建空白任务不会自动沿用该系列。
- 笔记是模型对已观察结果的总结，采用前仍要判断是否适合当前任务。

## 停止、失败与重试

| 状态或情况 | 操作 |
|---|---|
| **正在停止** | 等待状态收敛后再开始另一任务。停止不会撤销已经完成的操作。 |
| **执行异常**且有可用的**重试**按钮 | 先查看**错误详情**，排除连接等问题，再重试。重试沿用原配置，继续未完成部分，已保存的有效结果保留。 |
| 智能体已经接收任务但未完成 | 先通过**查看对话**检查原会话，处理其中的审批、输入或执行状态，再决定新建运行。不要重复派发可能已有副作用的任务。 |
| **运行中断** | 应用重启后不会自动续跑。已有结果保留，可检查后继续改进或新建任务。 |
| 需要修改配置来排错 | 使用**继续改进**或**新建任务**；直接重试不会应用新模型或新参数。 |

## 常见问题

### “开始”按钮不可用

检查任务名称、改进目标、模型和任务列表；补齐缺失文件。智能体模式需要完整配置；Skill 模式需要有效 Skill。在线教师的工具记录与文件内容发送许可也需要确认。

### 提示上下文容量不足

查看错误指向教师还是学生。新建或继续改进时，增大对应模型上下文、减少任务资料，或适当减小最大输出长度。直接重试会继续原配置中的未完成部分，不会扩大容量。

### 在线模型或连接不可用

到设置检查相应连接和凭据，再刷新模型列表。若连接所指模型或配置已经变化，重新选择模型并创建新的运行。

### 分数存在，但结果不可比较

查看具体提示和关联会话。Skill 未实际加载、执行未完成或依据不足时，已有内容可以检查，但不能认定为有效改进。先排除原因，再测试新的方案。

## 删除记录

1. 在 **历史记录**点击 **选择**。
2. 勾选记录，或用 **全选**选择当前已加载的可删除记录。
3. 点击 **删除所选记录**，核对数量并确认。

也可使用单条记录的删除按钮。运行、停止、改进笔记整理或关联智能体操作尚未结束时，记录可能无法删除。

删除后不能从 RSI 历史恢复该记录。先保存需要的成果。已导出的文件及关联智能体会话不会随 RSI 记录一起删除，关联会话需在智能体页面单独管理。
