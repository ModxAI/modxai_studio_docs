> v1.1.11

## 角色概览

| 角色 | 核心职责 | 默认状态 | 工具权限 |
|------|---------|---------|---------|
| 主角色 | 推理、工具编排、最终回复 | 必须启用 | 全部可选 |
| 评估角色 | 审查回复质量、提供反馈 | 默认启用 | 默认有限工具 |
| 摘要角色 | 上下文压缩、辅助总结 | 默认关闭 | 默认有限工具 |
| 记忆角色 | 模糊记忆搜索（微调模型） | 默认关闭 | 禁止使用工具 |
| 安全角色 | 高风险内容前置审查 | 默认关闭 | 默认禁止使用工具 |
| 委派角色 | 执行委派的子任务 | 按需添加 | 可独立配置 |

在线后端通过 OpenAI 兼容的 Chat Completions 协议调用云端模型。界面中的服务商包括 DeepSeek 与 OpenRouter。高级参数里的 OpenAI、Claude 缓存项只影响对应服务商的提示词缓存。

### 提示词

| 配置项 | 说明 |
|--------|------|
| 角色提示词模板 | 预设的角色行为模板 |
| 系统提示词 | 自定义该角色的行为指令 |

### 核心参数

| 参数 | 说明 | 主角色默认值 |
|------|------|-------------|
| 启用工具 | 是否允许该角色调用工具 | 开启 |
| 温度 | 控制输出随机性（0~1） | 0.6 |
| 最大生成长度 | 单次回复最大 token 数（0=自动） | 0 |
| 上下文长度 | 单次任务最大上下文长度（0=无限制） | 空 |

> 注意：这一项用来在角色上快速调整本地模型的上下文长度，不必先回到模型库。留空表示不覆盖模型库里的设定。`0` 表示不限制。长任务可在模型支持且资源允许时从 32K 开始尝试。

### 高级推理参数

| 参数 | 说明 | 主角色默认值 |
|------|------|-------------|
| 最大工具轮次 | 单次任务中工具调用的最大轮数 | 100 |
| 推理超时 | 单次推理最大等待秒数 | 600 |
| 快速模式 | 开启后工具调用前的过程反馈不进入下一轮上下文 | 关闭 |
| 思考模式 | 开启后，思考内容保留在回复中。关闭后，模型不再生成思考过程 | 开启 |
| 思考深度 | 本地模型的思考档位。档位越高，生成越慢。最高档为 Max | — |
| KV Cache / MTP | 本地 LLM 与多模态模型可调的推理优化参数 | — |

### 工具集配置

每个角色可独立选择允许使用的工具。支持两种模式：

- **自动选择**：运行时在已选工具范围内动态选择最合适的工具
- **固定加载**：始终加载全部已选工具

> 注意,任务执行时的可用工具完全遵循所选范围.包括自动选择或工具发现也不会调用未选的工具组


### MCP 工具（v1.1.12）

v1.1.12 可为主角色和委派角色选择 MCP 外部工具。先在**设置 → MCP**连接服务，再在角色的**工具集 → 配置工具**中选择。连接服务不会自动授予工具权限；其他角色不能据此使用 MCP 工具。完整步骤见[在智能体中使用 MCP](../mcp/agent-tools.md)。
