# 预设管理

> v1.1.11
> 2026-11

预设管理允许您保存当前工作台的完整参数配置，并在需要时快速恢复。适用于在不同任务类型之间切换配置的场景。

## 什么是预设

预设是工作台参数的**完整快照**，包含以下内容：

- 所有角色的参数配置（模型、提示词、推理参数等）
- 高级参数设置
- 工作区目录和 Skills 目录
- 指令设置（全局指令文件路径、搜索忽略文件、个人偏好）
- 运行时策略，包括自动审批（YOLO）开关

---

## 保存预设

1. 点击智能体页面右上角的**运行配置**，调整需要保存的参数。指令文件、搜索忽略文件和个人偏好在**设置 → 智能体**中配置并保存。
2. 点击参数面板顶部的**保存预设**（磁盘图标）。
3. 输入预设名称，按需展开**运行策略**检查自动审批开关。
4. 点击**保存预设**。

内置默认预设不可删除。

## 加载预设

1. 打开**运行配置**，在面板顶部的预设下拉框中选择目标预设。
2. 点击旁边的**加载预设**按钮。
3. 检查加载后的参数与自动审批设置，再发送任务。

加载会替换当前配置，也会恢复预设中的全局指令文件路径、搜索忽略文件和个人偏好。需要保留时，先另存为预设。在下拉列表中可删除非默认预设，删除前需确认。
