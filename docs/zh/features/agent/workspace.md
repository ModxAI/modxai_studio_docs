# 工作区浏览器

> v1.1.11
> 2026-11

工作区浏览器显示当前工作区的目录和文件，不限于智能体已经读写过的内容。可在应用内预览结果、打开文件，或另存到本机。

## 打开工作区资源

1. 在智能体页打开 **运行配置**，检查 **工作区目录**。需要时选择自己的项目目录。
2. 点击页面顶部的 **工作区资源** 按钮。
3. 展开左侧目录，选择文件。可按文件名搜索、筛选类型，或刷新当前目录。

抽屉宽度可拖拽调整。没有看到刚生成的文件时，先刷新，并确认当前会话使用的工作区路径。

## 资源预览

- 代码、普通文本、Markdown 和 HTML 支持内置预览，文本预览上限为 **10 MB**。
- 图片、音频和视频可按格式预览，媒体预览上限为 **32 MB**。
- 类型不支持或文件过大时，使用 **打开**，或点击 **下载到本机** 后用合适的应用查看。

预览不需要加载模型，也不会替代文件编辑器。

### HTML 交互

HTML 默认使用静态隔离预览，页面脚本和外部资源被禁用。

1. 确认文件来源与代码可信，再点击 **信任并启用交互**。
2. 检查确认框中的文件路径，确认后才会启用脚本、下载和页面确认框。
3. 不再需要交互时，点击 **返回静态预览**。

交互预览仍处于隔离环境，不能联网或访问主应用。切换文件或文件发生变化后，需要重新确认。不要为了查看陌生文件而直接启用交互。

## 标签页

选择文件会打开预览标签。可关闭单个标签，也可在标签菜单中关闭其它标签、右侧标签或全部标签。使用前进和后退按钮切换查看过的标签。

切换主工作区后，原工作区的标签和预览会清空。

## 工作笔记与任务关联

智能体可保存当前任务的交接笔记，记录结果、路径和待确认事项。后续任务读取相关历史时可参考这些笔记；这不等同于把所有历史对话都放进当前上下文。

在 **运行配置 → 任务关联** 中选择读取模式：

- **自动（最近 24 小时）**：读取近期任务背景。
- **指定会话**：选择至少一个历史会话；需要时开启 **同时读取近期任务**。
- **关闭**：不自动关联这些任务背景。

需要整理、编辑或导出长期记忆时，使用[记忆管理](../memory/overview.md)。定时任务可通过参数预设沿用配置，见[定时任务](../scheduler/overview.md)。

## 注意事项

- 开始任务前检查工作区目录，避免把输出写到错误位置。
- 要只读参考其它目录，使用[工作区引用](./attachments.md#工作区引用)，不要为此更换主工作区。
- 文件变更是否可以撤销，以对应变更卡片提供的操作为准。重要文件仍应保留备份，见[智能体概览](./overview.md)。
