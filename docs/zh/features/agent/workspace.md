# 工作区浏览器

> v1.1.10
> 2026-10

工作区浏览器用来查看智能体在当前工作区里读过或写过的文件，并在不同会话之间保留笔记和历史背景。文件操作默认限制在工作区目录内。只读引用其它目录的方法见 [附件与知识库](./attachments.md)。

## 资源预览

工作区提供资源预览器，选中文件即可在应用内查看，不必先用外部程序打开。

可以预览的内容包括：

- 常规文本与代码文件
- **JSONL** 文件
- **HTML 实时预览**：HTML 文件可以直接看到渲染结果

可预览文件的大小上限已提高。超过上限时，界面会提示无法完整预览，或只显示部分内容。具体字节数以界面提示为准。

---

## 标签页

预览器以标签页打开多个文件。标签支持多种关闭方式，可以关掉当前页，也可以一次处理一组相关标签。

工作台参数窗口可以横向拖拽改变宽度，方便同时看预览和参数。

---

## 工作笔记

工作笔记可以跨会话共享。用它记下路径、结论或待办，这些内容不会只留在某一轮对话里。

需要把结论沉淀成可导出的记忆时，使用回复上的偏好或规避反馈，或在 [记忆管理](../memory/overview.md) 里整理。

---

## 任务关联

在工作台参数里可以把当前任务关联到历史会话。关联之后，智能体可以读取那些会话中的背景，用来继续未做完的工作，或对照之前的决定。

定时任务如果要沿用同一套工作台参数，在创建任务时选择参数预设。见 [定时任务](../scheduler/overview.md)。

---

## 注意事项

- 未指定工作区时，系统使用临时目录下的默认工作区。可在会话配置中改成自己的目录
- 外部工作区引用是只读的，不能在被引用的目录里写文件
- 预览 HTML 或 JSONL 不需要为此单独加载模型
- 智能体改过的文件仍可在进度节点上 **回滚**，见 [智能体概览](./overview.md)
