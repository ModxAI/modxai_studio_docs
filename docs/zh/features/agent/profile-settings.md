## 全局指令文件

指令文件是一个纯文本文件，其中的内容会作为系统指令注入到智能体的上下文中，影响智能体的行为模式。

### 配置方式

打开**设置 → 智能体**，找到**全局指令文件**和**个人偏好**。工作区目录在智能体页面的**运行配置**中设置。

#### 方式一：自动检测（推荐）

1. 设置**工作区目录**
2. 系统会自动检测工作区根目录下的 `AGENTS.md` 类文件
3. 检测到后自动生效

#### 方式二：手动指定

1. 点击**浏览指令文件**
2. 选择一个纯文本文件
3. 点击页面下方的**保存**，检查指令文件下显示的生效路径

### 指令文件格式

- 纯文本文件（`.md`、`.txt` 等）
- 内容会作为系统提示词的一部分注入
- 建议包含项目规则、行为约束、输出格式等指令

工作区中检测到的指令文件优先于手动选择的文件。请以页面显示的生效路径为准。

## 个人偏好

个人偏好允许您添加多条简短描述，提醒智能体您的习惯和偏好。

### 添加偏好

1. 在**设置 → 智能体**中找到**个人偏好**
2. 点击**添加偏好**
3. 输入描述（每条不超过 200 字）
4. 可添加多条偏好，完成后点击**保存**

### 偏好示例

- 「请始终使用中文回复」
- 「回复尽量简洁」

### 管理偏好

- 点击偏好条目旁的删除按钮移除，再点击**保存**
- 所有偏好会以较高权重合并注入到智能体的系统提示词中

## 工作区自动检测

设置工作区目录后，系统会在以下位置自动检测指令文件：

- 工作区根目录下的 `AGENTS.md`
- 工作区根目录下的 `AGENTS.txt`
- 工作区根目录下的 `agents.md`

系统按上列顺序查找，使用第一个找到的文件。检查页面显示的生效路径，避免误用另一份指令。

## 搜索忽略文件

在**设置 → 智能体 → 全局指令文件**中，可通过**浏览忽略文件**选择文本规则文件，再点击**保存**。工作区根目录的 `.modxignore` 优先于手动选择的文件；没有指定文件时使用内置忽略规则。此设置用于文件搜索，不代替工具权限或审批。
