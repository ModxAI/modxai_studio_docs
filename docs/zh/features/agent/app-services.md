# 让智能体操作应用功能

智能体可以在对话中查询或启动数据处理、模型训练、自我改进和定时任务。也可以查看进度和结果，无需在对话里猜测文件位置。

## 开始使用

1. 在智能体工作台点击标题栏的扳手，打开主角色的工具选择。
2. 展开所需分类，如**数据处理**或**定时任务**。只查询时，仅勾选读取工具；需要启动或修改时，再选择对应的操作工具。确认后返回会话。
3. 在对话中说明要做的事、使用的文件或预设、输出目录，以及是否可以立即开始。涉及启动训练或定时执行时，建议先让智能体列出配置供你核对。
4. 若应用要求授权文件或确认操作，先核对范围，再决定是否批准。后台任务继续运行时，可从会话结果卡片或[消息盒子](./inbox.md)查看状态。

例如：「先列出可用的文本处理预设。用我选定的预设检查工作区里的 Markdown 文档，先告诉我输入和输出路径，不要启动。」

可用操作取决于主角色的工具和当前资源权限。工作区外文件可能需要单独授权；训练和自我改进仍需各自所需的模型与环境。浏览结果或显示“已接收”不等于任务已经完成。
