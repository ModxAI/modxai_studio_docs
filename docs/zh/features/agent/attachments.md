# 附件与知识库

> v1.1.11
> 2026-11

在智能体输入框左侧点击 **+**，可添加本地文件、连接知识库，或引用其它目录。先确认附件和引用范围，再发送任务。

## 本地附件

1. 点击 **+ → 添加文件**，选择一个或多个本地文件。
2. 等待文件加入输入框附近的附件列表。也可以把文件拖入输入区，或粘贴剪贴板中的文件。
3. 输入任务，说明要处理哪些文件以及希望得到什么结果，再发送。

发送前可从附件列表移除不需要的文件。切换会话时，各会话保留自己的附件草稿。

常见类型包括：

| 类型 | 常见格式 |
|------|----------|
| 图片 | PNG、JPG、JPEG、WebP、BMP |
| 音频 | MP3、WAV、OGG、M4A、AAC、FLAC |
| 视频 | MP4、WebM、MOV、M4V、AVI、MKV |
| 文件 | TXT、Markdown、PDF、Office 文档、代码、ZIP 等 |

文件成功附加，不代表当前模型能直接理解所有内容。图片理解需要合适的多模态模型；音视频、文档和压缩包的处理还取决于可用工具与文件内容。不能直接把文件夹作为附件上传，需要引用目录时使用下方的工作区引用。

## 知识库连接

知识库为任务提供可检索的资料。先在[数据处理](../dataset/rag.md)中生成并导入知识库，再连接到会话。

### 连接与断开

1. 点击 **+ → 知识库连接**。
2. 选择已有知识库，按需要调整检索参数。
3. 确认后，输入框附近显示知识库名称。
4. 发送问题，并说明需要参考哪些资料。

点击知识库标签上的关闭按钮可断开连接，不会删除知识库。聊天和智能体可以连接同一个知识库，底层资料共享，检索设置分别保存。

### 检索设置

- **检索方式**：混合检索（推荐）、双路融合检索、向量检索、向量+重排检索或文本检索。
- **检索数量**：每次返回多少条结果。
- **重排候选数量**：进入重排步骤的候选数量。
- **分数阈值**：过滤低于阈值的结果。
- **最大上下文长度**：限制一次检索返回的文本量。
- **检索提示词**：补充检索要求。

使用向量检索时，应准备与知识库匹配的向量模型；使用重排时，还需准备重排模型。没有结果时，先检查知识库是否已导入、模型是否就绪，以及阈值是否过高。

## 工作区引用

**工作区引用(只读)** 用来让智能体读取当前工作区以外的目录，例如已有项目资料。它不会把该目录改成当前任务的写入工作区。

1. 点击 **+ → 工作区引用(只读)**。
2. 在系统目录选择窗口中选择一个已有目录。
3. 检查输入框附近显示的引用目录，再发送任务。

可重复添加不同目录。点击引用标签上的关闭按钮可移除该引用。引用按会话保存；不要引用包含本次任务不需要的私密资料的上级目录。

需要让任务在某个目录里创建或修改文件时，在 **运行配置** 中设置当前工作区，见[工作区浏览器](./workspace.md)。
