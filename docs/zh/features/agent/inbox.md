# 消息盒子

集中查看智能体和定时任务的通知，找回任务结果，或打开待回复、待审批的会话。

1. 点击**消息盒子**图标。未读角标表示还有未读的任务消息。
2. 按时间浏览，或使用**搜索会话或任务**、**仅看未读**缩小范围。
3. 点击一条消息，回到相应会话或运行记录。若消息提示等待审批，请在原会话查看具体请求。
4. 点击**清除未读（全部标为已读）**只改变阅读状态；**清空已读**才会把已读通知从消息盒子移除。两者都不会删除原会话或任务记录。
