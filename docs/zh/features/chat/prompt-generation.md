# 提示词优化

> v1.1.11
> 2026-11

把任务描述整理成提示词，再由你检查并放入聊天或智能体输入框。生成提示词不会直接执行任务，也不会自动发送结果。

## 使用前准备

先在[模型中心](../models/overview.md)加载可用于文本生成的本地模型，并按该模型要求准备运行环境。仅配置在线智能体模型，并不满足这里的本地模型条件。

## 生成与使用

1. 在聊天或智能体输入框旁点击魔法棒按钮，打开 **提示词生成**。
2. 按需要选择 **系统提示词模板** 和用户提示词模板。选择系统模板时，会尝试自动选中配对的用户模板，也可自行更换组合。
3. 在 **用户输入内容** 中填写目标、背景、约束和希望得到的格式。
4. 点击 **生成**，等待内容出现在 **生成结果** 中。
5. 直接编辑结果，删除模型猜测或增加的无依据条件。
6. 点击 **添加到输入框**，用结果替换当前输入框文字。检查后再手动发送；原草稿仍需保留时，先复制备份。

系统模板定义改写要求，用户模板描述如何处理原始输入。系统模板、用户模板和用户输入内容均可编辑，各最多 **4,000 字符**。

点击 **取消** 只关闭窗口，不会把结果填入输入框；不要把它当作清空已输入内容的操作。

## 自定义模板

### 引用原始输入

在用户提示词模板中使用单层花括号占位符，例如：

```text
请整理下面的任务描述，保留原意，不补造背景；仅输出改写后的提示词：
{userPrompt}
```

生成时，`{userPrompt}` 会替换成 **用户输入内容**。也支持 `{content}`、`{user_content}`、`{query}`、`{originalPrompt}`、`{input}` 和 `{text}`。

如果填写了用户模板但没有占位符，原始输入不会自动追加到模板后。用户模板留空时，会直接使用原始输入。

### 保存模板

1. 编辑系统或用户模板，至少保留一项非空内容。
2. 点击 **保存模板**。
3. 输入至少两个字符的名称，可填写说明，再确认。

名称不能包含 `\ / : * ? " < > |`。保存时只保存非空的系统和用户部分，并在名称后分别添加 `_system`、`_user`，供后续配对使用。

### 删除模板

选择要删除的模板，点击对应删除按钮并确认。删除会同时处理同名配对的系统模板和用户模板，不能撤销。删除前先复制仍需保留的内容。

## 常见问题

### 无法生成

检查本地模型是否已加载、**用户输入内容** 是否为空，以及是否已有一次生成尚未结束。模型加载和环境问题见[模型加载](../models/overview.md)。

### 结果为空或不合适

先查看错误提示和模型状态。没有报错但内容不合适时，调整模板、补充真实约束后重新生成。清楚完整的任务可以直接发送，不必先优化。

### 原始输入没有出现在结果中

检查用户模板中的占位符拼写，建议使用 `{userPrompt}`。占位符负责把原始输入交给模型，不保证模型在结果中逐字保留输入。
