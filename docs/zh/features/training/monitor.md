# 训练监控模块详解

> v1.1.11
> 2026-11

在「自我改进 → 训练 → 监控」查看训练进度、指标曲线和日志，也可回顾已经结束的任务。

## 使用前准备

先在[准备](./prepare.md)中创建并启动训练任务。已有任务也可以直接从监控页的任务列表中选择；尚未产生训练记录的任务不会有可分析的曲线。

## 查看训练

1. 打开「自我改进 → 训练 → 监控」。从准备页成功启动训练时，也会自动进入此页。
2. 在顶部「选择训练任务」中选中目标任务。
3. 运行中的任务显示「实时监控中」；非运行中的任务加载已有记录，显示「历史回顾模式」。无需手动切换模式。
4. 查看进度、当前指标和曲线。展开「其它图表」可查看更多指标，页面底部是「训练日志」。
5. 需要停止训练时，返回[准备](./prepare.md)点击「停止训练」，并等待状态更新。

进度和剩余时间用于观察运行情况，不代表模型质量。确认任务最终状态，并结合日志判断本次训练是否正常结束。

## 界面布局

| 区域 | 显示内容 |
|------|----------|
| 任务选择 | 任务名称和状态，可搜索任务 |
| 进度 | 当前步骤、总步骤、训练进度、预计剩余时间 |
| 当前指标 | 当前损失、学习率、处理速度（SPL/s，即样本/秒） |
| 主要图表 | 训练损失、困惑度 |
| 其它图表 | 梯度范数、学习率变化、评估损失、训练速度 |
| 训练日志 | 带时间的训练事件和指标记录 |

## 指标图表

| 指标 | 如何阅读 |
|------|----------|
| 训练损失 | 观察总体变化趋势；单次波动不能直接判断训练失败 |
| 困惑度 | 反映模型对训练文本的预测不确定性；适合在相同数据和设置下比较，不设通用合格值 |
| 梯度范数 | 观察更新幅度是否出现持续异常变化，结合学习率和数据排查 |
| 学习率 | 查看学习率是否按预热和调度设置变化 |
| 评估损失 | 来自训练过程中的评估；需要独立评估文件和已开启的评估策略 |
| 训练速度 | 每秒处理的样本数，受模型、序列长度、批次、设备和保存操作影响 |

没有评估损失曲线时，先检查训练参数中的评估文件和评估策略。训练中评估损失与[评估模块](./evaluate.md)的基准分数不是同一指标。

## 曲线设置

点击任务选择区右侧的齿轮按钮打开「曲线设置」：

- **平滑强度**：`0%` 显示原始数据；提高数值可让趋势更平滑。
- **滑动窗口**：窗口越大，局部波动越平缓。
- **EMA 系数**：数值越大，对新数据的变化越敏感。
- 点击「应用」确认，或用「重置默认」恢复默认设置。

可用鼠标滚轮缩放图表，缩放后拖动平移。平滑只用于显示趋势；排查突变时将平滑强度调到 `0%`，再结合日志查看。

## 图表数据累积机制

历史记录按训练任务保存。重新启动同一任务后，历史中可能包含多次运行，步数也可能重新开始。这不表示自动断点续训。

需要清楚区分不同参数方案时，建议分别创建新任务。切换页面不会主动停止训练，返回后可重新选择任务查看。

## 训练日志

日志包含训练开始、训练步骤、评估、检查点保存和结束等事件。实时列表最多显示最近 `200` 条；历史回顾读取已保存的训练记录。

这里显示的是训练事件与指标记录，不应将其视为所有终端输出的完整副本。任务失败时，同时查看失败提示中的信息。删除训练任务会删除该任务的日志记录。

## 实时监控模式

运行中任务会随着新指标更新图表。更新间隔受「日志记录步数」影响，预设为每 `10` 步记录一次，不是每秒固定刷新一次。

实时曲线最多显示最近 `400` 个点。模型加载、数据准备或保存期间，指标可能暂时不更新；先查看日志和任务状态，不要仅凭曲线停顿判断失败。

## 历史回顾模式

选择非运行中的任务，可查看已保存的指标和事件，包括已完成、已停止或失败的任务。历史曲线最多显示最近 `4000` 个点，并不保证一张图包含全部历史。

如果没有曲线，确认该任务是否实际开始训练并产生指标。若提示历史加载失败，可重新选择任务重试。

## 使用建议

- 在同一数据和设置下观察趋势，不用固定的损失或梯度阈值判定所有模型。
- 训练损失下降、评估损失持续上升时，检查是否过拟合，再考虑调整训练轮数、学习率或数据。
- 要比较训练后的实际能力，继续做基准评估和交互测试。
