## 环境要求

在[设置 → 系统](../settings/environment.md)安装具备训练能力的环境。训练支持 CPU 或 NVIDIA CUDA；内存、显存和磁盘需求取决于模型、训练方式、序列长度、批次和检查点保存设置，没有适用于所有模型的固定最低显存值。

准备完整的可训练模型目录，包含配置、权重和可用分词器，不能使用 GGUF 推理文件。数据处理生成的 SFT/预训练文件优先选择 `train/final_dataset.jsonl`，需要训练中评估时另选 `eval/final_dataset.jsonl`。详见[准备](./prepare.md)。

## 功能概述

1. 在[准备](./prepare.md)选择 SFT 或预训练，填写模型、数据及输出目录，应用参数后点击「开始」。
2. 在[监控](./monitor.md)确认任务运行，查看损失、速度和日志。
3. 训练结束并有检查点后，在[评估](./evaluate.md)比较基准表现，在[测试](./test.md)中检查自己的问题。
4. 确定检查点后，按[量化指南](./package.md)导出 GGUF。

数据处理可以导出 DPO 偏好数据，但此训练入口不提供 DPO 训练类型。

## 界面布局

| 标签 | 用途 |
|------|------|
| 准备 | 创建任务，设置参数，开始或停止训练 |
| 监控 | 查看当前任务进度和保存的历史指标 |
| 评估 | 使用固定基准比较训练前模型及检查点 |
| 测试 | 输入问题，检查所选检查点的回答 |
| 量化 | 将支持的训练产物导出为 GGUF |

## 功能模块

### 准备模块

选择训练类型、设备和模板，配置训练文件、模型目录与输出目录。SFT 模板默认启用 LoRA，预训练模板不使用 LoRA。模型和参数仍需匹配，模板不保证适合所有硬件。

### 监控模块

选择运行中的任务查看实时指标；选择非运行中的任务读取已有历史。主要图表包括训练损失、困惑度、学习率、梯度范数、评估损失及速度。实时曲线最多显示最近 400 个点，历史曲线最多 4000 个点，不保证展示全部历史。

训练中的评估损失需要独立评估文件及有效评估策略，与下面的基准评估不同。

### 评估模块

选择训练任务、一个或多个检查点，也可包含训练前模型。内置基准为 IFEval、MMLU-Pro、GSM8K 和 HellaSwag，可选择快速、扩展或完整规模。

按提示准备资源，点击「检查并继续」，通过后再点击「开始评估」。结果包括分数矩阵、单项趋势、逐题详情和两模型比较。「本项最高」表示单项基准结果，不是综合最优模型推荐。

评估记录可在「评估历史」查看、继续、复制配置、重新计算或导出为 JSONL。当前评估页没有自定义问答样本入口。

### 测试模块

选择已结束任务中的可用检查点，设置推理参数和可选系统提示词，启动后输入问题。LoRA 检查点还需要原始基础模型。

每次输入独立生成，不携带之前问答作为上下文。更换参数或检查点前先退出测试。

### 量化模块

在「量化」页选择模型产物、输出位置和可用量化选项，导出 GGUF。模型支持条件和完整操作见[量化指南](./package.md)。

## 训练任务机制

任务列表显示等待中、运行中、已完成、已停止或失败/错误。任务完成只代表训练运行结束，不保证模型回答正确。

检查点按照保存策略、保存步数和最大保留数量保存；超过保留数量时，旧检查点可能被清理。需要特定检查点时先备份。

重新选择已有任务再点击「开始」，不会自动恢复上次训练进度。断点续训必须设置可用的恢复检查点，详见[准备页](./prepare.md#断点续训)。

## 训练参数体系

参数分为数据、训练、LoRA、优化、日志和通用配置，完整说明见[准备页](./prepare.md#参数配置)。

- 必需路径：训练数据、可训练模型目录、可写输出目录。
- 训练中评估：单独提供评估文件并开启评估策略。「评估集采样比例」对该文件取样，不从训练集自动划分。
- 资源占用：主要受模型大小、训练方式、批次和序列长度影响。
- 早停：按连续无改善的评估次数判断，不按训练步数计数。
- 对比实验：保持数据、种子和参数一致，不保证跨设备结果完全相同。

## 参数模板机制

可以加载预设或自定义模板，在「训练参数配置」中修改后点击「应用」。修改用于当前任务，不会覆盖原模板；要复用时，点击模板旁的保存图标另存为自定义模板。

部分参数位于折叠组中，可按需展开。取消或关闭抽屉不会应用本次未确认的编辑。
