# 训练评估模块详解

> v1.1.11
> 2026-11

在「自我改进 → 训练 → 评估」中，用固定基准比较训练前模型和检查点，查看分数、逐题回答与差异，并保存评估记录。

## 使用前准备

- 已安装支持训练模型推理的[运行环境](../settings/environment.md)，并有已经结束的训练任务。
- 保留任务所用的基础模型、分词器和要评估的检查点文件。LoRA 检查点需要对应的基础模型；GGUF 文件不能用于这里的评估。
- 准备足够内存或显存。每增加一个模型或评估项，运行量都会增加。
- 按页面提示准备题库和评分组件。缺少的资源需要联网下载；资源准备完成后，模型评估使用本地模型运行。

任务列表包含已完成、已停止、失败或错误的任务。只能选择实际可用的检查点；任务记录存在不代表权重文件完整。

## 评估流程

1. 打开「自我改进 → 训练 → 评估」，选择「训练任务」。
2. 选择一个或多个「检查点」，也可点击「全选」。保留「包含训练前模型」可与原始基础模型比较；只评估训练前模型时，可以不选检查点。
3. 选择一个或多个「评估集」。每个已选评估项旁显示当前规模的题数和资源状态。
4. 点击「评估参数配置」，选择评估规模、最大输出 tokens、运行设备和可选的额外思考模式，点击「应用」。
5. 若所选规模缺少题库，点击该项的下载图标。IFEval 还需要评分组件，按提示点击「准备评分组件」。等待显示「已准备」；下载失败时重试，下载或校验中可点击进度图标取消。
6. 点击「检查并继续」。系统检查资源、模型文件、环境和题目长度。检查过程中可取消；失败时按页面提示处理后重新检查。
7. 显示「可以开始」后，点击「开始评估」。检查通过本身不会启动模型评估；修改配置后需要重新检查。
8. 在结果页查看进度和已完成的结果。可以离开页面，稍后通过「查看进度」或「评估历史」返回。

需要停止时，返回评估配置页点击「停止」，等待状态变为「已停止」。若显示停止失败，按提示重试，不要把发出停止请求当作已停止。

## 内置基准

| 基准 | 衡量内容 | 总览分数 |
|------|----------|----------|
| IFEval | 回答是否遵循题目中的格式和约束 | 严格满足整题要求的比例 |
| MMLU-Pro | 专业知识与推理选择题 | 答案准确率 |
| GSM8K | 小学数学应用题 | 最终数值答案准确率 |
| HellaSwag | 从候选内容中选择自然的后续情境 | 按长度归一化后的候选选择准确率 |

当前评估页使用这些内置基准，不提供自定义 `prompt/completion` 样本文件入口。要验证自己的问题，请使用[测试模块](./test.md)。

## 评估参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 评估规模 | 快速 | 可选「快速」「扩展」「完整」；题数以各评估项旁的显示为准 |
| 最大输出 tokens | 2048 | 生成答案的长度上限，范围 1–32768 |
| 运行设备 | 继承训练任务 | 可选继承训练任务、自动（CPU/CUDA）、CPU、GPU（CUDA） |
| 额外思考模式 | 关闭 | 仅在模型及其模板支持时有效 |

「快速」适合先检查流程；「扩展」增加题数；「完整」使用完整固定题库。较小规模的结果波动更大，不宜直接当成模型能力的最终结论。

评估页不提供温度、Top P、Top K、随机种子或自定义采样比例设置。这里的设置与交互测试参数相互独立。

题目加生成预算不能超过模型的上下文容量。若提示输出预算过大，可降低「最大输出 tokens」后重新检查；若题目本身已超出容量，需要选择能容纳题目的模型。

## 查看结果

### 矩阵总览

每行是一个模型，每列是一个评估项。分数以百分比显示：

- 点击分数可查看对应题目、模型回答、参考答案或要求以及评判结果。
- 选择「显示差异」筛选未符合要求的样本；可刷新或加载更多。
- 「本项最高」只比较同一评估项中完整且无执行失败的结果，不是所有基准的综合排名。
- 包含训练前模型且有可比较的完整结果时，显示相对训练前模型的百分点变化。
- 未完成的单元格同时显示完成数量；「执行失败」不同于模型答错。

### 单项趋势

选择一个评估项，比较本次运行中各模型的完整分数。尚未完成或有执行失败的结果不进入趋势图。

### 两模型比较

1. 选择第一个模型、第二个模型和评估项。
2. 点击「两模型比较」，并排查看同一题的结果。
3. 可按「第二个模型更好」「第一个模型更好」「两者均对」「两者均错」「无法比较」筛选，或勾选「显示差异」。

比较的是本次运行中的模型。两者均错但文字不同，不代表其中一个一定更好。

## 评估历史

点击「评估历史」，可按训练任务、状态和日期筛选记录。

| 操作 | 用途 |
|------|------|
| 查看 | 打开该次运行的分数和逐题结果 |
| 复制配置 | 将配置带回评估页，检查后再启动新的运行 |
| 继续评估 | 用于已停止、失败或中断的运行；返回配置页检查后继续，可复用符合条件的已完成结果 |
| 重新计算 | 返回配置页，以不复用已有结果的方式重新评估 |
| 导出 | 下载 JSONL 文件，包含配置、汇总和逐题结果 |
| 删除 | 确认后删除非运行中的评估记录；不会删除训练模型和检查点，也不会清除所有可复用结果 |

正常评估可能复用相同模型、题目和设置已有的结果。「可以开始」附近会提示可复用数量和仍需计算的数量。需要重新生成全部结果时，使用「重新计算」。

## 注意事项

- 同时只能运行一项评估。已有运行时，先查看进度或停止它，再开始另一项。
- 部分完成的分数不能与完整分数直接比较。失败或中断后，已经完成的样本仍可查看，可从历史继续。
- 基准分数衡量的是对应题库上的表现，不保证业务问题、中文能力或模型回答的事实正确性。
- 比较检查点时保持评估规模和生成设置一致，再使用自己的问题复核。
- 导出文件可能包含本地模型路径、题目和模型回答，分享前检查内容。

## 与测试模块的区别

评估模块用于固定题库的批量评分和模型比较；[测试模块](./test.md)用于手动输入自己的问题、检查实际回答。建议先用评估筛选检查点，再交互测试，最后选择用于[量化](./package.md)的模型。
