# 在智能体中使用

> v1.1.12
> 2026-11

连接 MCP 服务后，为角色选择允许调用的工具。也可授权智能体协助配置服务，但保存连接和授予工具权限仍需分清。

## 选择角色工具

1. 在 **设置 → MCP** 确认服务已启用、显示**已连接**，并能查看工具目录。
2. 回到智能体页面，点击右上角**运行配置**（齿轮图标）。
3. 选择主角色或委派角色，开启**启用工具**，在**工具集**中点击**配置工具**。
4. 找到 **MCP 工具**，按服务选择本次任务需要的工具，并确认选择。
5. 发送一个范围明确的任务，例如读取指定项目的资料。查看工具调用结果，再决定是否扩大任务范围。

目前 MCP 工具可配置给主角色和委派角色，不要假定评估、摘要、记忆或安全角色也能使用。

开启**自动**模式后，只在已选范围内挑选工具；固定模式加载已选工具。两种模式都不会因为服务已连接而自动授予全部工具。

## 查看执行结果

任务中的工具调用会显示执行状态和结果。需要审批时，先确认目标、操作及发送的数据，再批准或拒绝。

- 目录中存在工具，不代表账号对所有目标都有访问权限。
- 工具返回成功后，仍应检查具体结果；模型的总结不能代替服务商端的实际状态。
- 超时、断线或取消后，写入操作可能已在外部服务发生。先核实目标状态，再决定是否重试，不要连续重复提交。
- 服务新增工具后，重新检查角色的工具选择，不要假定原选择自动包含新增工具。

## 让智能体协助接入

适用于您已有可信服务的接入说明，希望智能体协助填写配置的情况。

1. 关闭**自动审批**，为主角色选择 **MCP 管理**中的**查询 MCP 服务**和**注册 MCP 服务**。
2. 向智能体提供服务用途、官方接入说明和允许使用的工具范围。只提供非敏感配置，不在聊天中粘贴令牌、密码、客户端密钥或浏览器验证码。
3. 在审批卡片中核对服务名称、连接配置、修改范围及工具授权范围。修改已有服务会影响使用它的其他会话。
4. 需要凭据时，填入卡片中的私密输入框；需要账号授权时，批准后按提示完成浏览器授权。凭据不应通过普通聊天补交。
5. 等待注册结果，再到 **设置 → MCP** 检查服务。新授权工具在后续模型请求中生效，不会在同一批请求里立即可用。

审批中可能显示三种范围：

| 范围 | 含义 |
| --- | --- |
| 仅保存服务 | 保存连接，不授权当前会话使用工具 |
| 指定工具 | 仅向当前会话的主角色授权列出的工具 |
| 本次发现的全部工具 | 授权本次发现的工具集合，不包含以后新增的工具 |

服务配置全局共用，但这次授权只给当前会话的主角色，不会一并授予其他会话或委派角色。

本地服务的程序和依赖须先准备好。智能体如需下载程序、安装依赖或创建文件，应另行说明并获得您的允许；注册服务本身不会安装依赖。第三方环境应与 ModxAI 自身环境分开。

### 注册结果不明确

如果注册等待超时或返回状态不明确，让智能体查询**原操作的状态**，并检查设置中的已有服务。不要立刻重复注册，避免创建重复连接或覆盖共用配置。
