# 在智能体中使用

> v1.1.12
> 2026-11

连接 MCP 服务后，在当前会话中为角色选择工具，再发送任务。服务可以共用，但工具选择要按会话和角色检查。

## 选择角色工具

1. 在 **设置 → MCP** 点击已添加的服务卡片，确认详情显示**已连接**，并已取得所需工具。
2. 回到要使用工具的智能体会话，点击右上角**运行配置**（齿轮图标），在**角色参数**中展开主角色或委派角色。
3. 找到**工具集**，打开**启用工具**开关，点击**配置工具**。已有选择时，按钮会显示**已选 N 项**。
4. 在工具选择窗口展开 **MCP → 服务名称**，勾选所需工具，点击**确定**。若保存失败，窗口会保留选择，请处理提示后重试；点击取消不会提交此次改选。
5. 发送一个范围明确的小任务，例如读取指定项目的一份资料。检查实际工具调用及返回内容，再扩大任务范围。

仅主角色和委派角色可配置 MCP 工具。委派调用需要主角色和对应委派角色都开启**启用工具**，并选中所需 MCP 工具，不能只给委派角色勾选。

**自动**勾选项用于在已选范围内按需挑选工具；取消勾选后使用固定选择。它不是自动审批，也不会自动授予未选中的工具。

## 查看执行结果

任务中的工具调用会显示状态和结果。出现审批时，先核对操作、目标和发送的数据，再决定是否允许。

- 服务已连接，不代表账号能访问所有项目或资源。
- 模型总结不能代替实际结果；涉及修改时，必要时到服务商端核实。
- 超时、断线或取消任务，不一定撤销已经发生的外部操作。创建、发送、修改或删除的结果不明确时，先核实再重试。
- 服务新增工具后，需要重新检查并勾选。删除后重新添加的服务，也要重新配置工具选择。

## 让智能体协助接入

已有可信的接入说明时，可以让智能体协助检查环境和填写配置。

1. 先关闭当前会话的**自动审批**，以便逐项检查接入操作。
2. 打开主角色的工具选择窗口，在 **内置 → 执行**中勾选 **MCP 管理**，点击**确定**。该组提供查询和注册服务的能力，不是外部服务工具本身。
3. 提供服务的官方接入说明、用途及允许使用的工具范围。不要在聊天中粘贴令牌、密码或客户端密钥。
4. 出现接入确认时，核对服务名称、共用配置的影响和本会话的工具使用范围；展开详情检查命令或地址。
5. 需要凭据时，在私密输入框中填写。需要浏览器授权时，点击**允许**后按浏览器提示完成，再等待注册结果。不要把凭据补发到普通聊天中。
6. 注册成功后，按结果检查服务是否连接、工具是否已授权。若只保存了服务，按本文前面的步骤手动选择工具，再发一个简单任务验证。

确认内容可能表示：

| 范围 | 含义 |
| --- | --- |
| 仅保存服务 | 保存连接，不给当前会话增加工具权限 |
| 指定工具 | 当前会话的主角色可使用列出的工具 |
| 本次发现的全部工具 | 当前会话的主角色可使用这次发现的工具，不包含以后新增的工具 |

服务配置全局共用，接入时授予的工具只作用于当前会话主角色，不自动授予其他会话或委派角色。如果接入期间改过工具选择，注册结果可能提示未自动启用；检查当前选择后手动补选，不要重复注册。

需要下载程序、安装依赖或创建文件时，先核对智能体提出的来源、路径和具体操作。第三方程序应使用独立环境，不安装进 ModxAI 自身运行环境。

### 注册结果不明确

让智能体查询刚才那次注册的结果，并到 **设置 → MCP** 检查已有服务。不要立即重新添加，避免重复连接或覆盖共用配置。
