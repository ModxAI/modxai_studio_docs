# 快捷添加与授权

> v1.1.12
> 2026-11

快捷添加预填服务的连接信息。需要账号授权的服务会打开浏览器，由您选择账号和访问权限。

## 使用前准备

- 需要浏览器授权时，使用连接本机后端的桌面应用，并确认浏览器可以访问服务商网站。
- 准备服务所需的账号和权限。组织资源可能需要管理员批准。
- 本地程序类预设还需要在后端电脑安装对应程序和依赖，见[自定义服务](./custom-service.md#本地程序)。

## 添加服务

1. 打开 **设置 → MCP**。
2. 在**快捷添加**中搜索服务名称，或按分类筛选。
3. 点击服务卡片的添加按钮。
4. 需要授权时，在弹窗的**授权详情**中查看授权来源和申请权限，再到浏览器中完成授权。若显示设备验证码，按服务商页面要求输入；不要把验证码发送到聊天中。
5. 回到 ModxAI，等待授权和保存完成，再确认卡片显示**已连接**。
6. 打开**详情**查看工具。接着[为角色选择工具](./agent-tools.md#选择角色工具)。

新建的浏览器授权预设在授权成功后才保存，并尝试连接。关闭授权窗口或点击**取消**不会完成这次添加。已有服务重新授权时，仍须等待保存结果。

无需浏览器授权的预设会直接保存并尝试连接；例如本地程序，连接是否成功仍取决于后端电脑的环境。

## 确认访问范围

- 服务商可能只允许访问您选择的工作区、项目或仓库。请在授权页面确认具体范围。
- GitHub 快捷预设使用只读服务。按页面提示选择允许访问的仓库并完成安装；组织仓库可能还需管理员批准。不要据此预期创建提交、修改仓库等写入操作。
- 页面中的预设和可用工具以当前版本及服务商返回结果为准。未显示的服务可按其接入说明配置为[自定义服务](./custom-service.md)，不能仅凭名称假定支持。

## 授权未完成

| 现象 | 下一步 |
| --- | --- |
| 浏览器没有打开，或中途关闭 | 在授权弹窗点击**重试**，继续浏览器流程 |
| 授权被拒绝或已过期 | 重新发起授权，确认允许的账号和权限 |
| 提示仅支持本机后端 | 改用连接本机后端的桌面应用；不要通过关闭浏览器安全限制绕过 |
| 提示需要已注册的客户端 | 查看服务商接入说明；若提供公开客户端，按说明填写高级设置，不能用客户端密钥代替公开客户端 ID |
| 授权成功但连接失败 | 检查卡片和详情中的错误，再按[管理与排错](./manage.md)处理 |

## 取消授权

在服务**详情**中点击**取消授权**并确认。这会清除本机保存的授权并断开连接，保留服务配置和工具选择。

**这不是撤销服务商端的授权。** 如需彻底撤销访问，还应到服务商的账号设置中移除授权。重新使用时需再次授权。
