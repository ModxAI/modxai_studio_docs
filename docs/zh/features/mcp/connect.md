# 快捷添加与授权

> v1.1.12
> 2026-11

快捷添加已填好服务的连接参数。需要账号授权时，ModxAI 会打开浏览器，由您选择账号和访问范围。

## 使用前准备

- 浏览器授权需要连接本机后端的桌面应用，以及可访问服务商网站的网络。
- 准备服务所需账号。工作区、项目或组织资源可能需要管理员批准。
- 本地程序预设需要相应运行环境。例如 Playwright 使用 Node.js/npm，首次启动可能下载程序包。请先核对其运行要求。

## 添加服务

1. 打开 **设置 → MCP**，在**快捷添加**中搜索名称或按分类筛选；未找到时可翻页查看。
2. 点击目标卡片或右侧 **＋**。已添加的服务会显示重连、编辑和启停控件，不需要重复添加。
3. 需要授权时，等待浏览器打开，在服务商页面确认账号、工作区和权限。ModxAI 弹窗中的**授权详情**可查看授权来源和申请权限。
4. 完成后回到 ModxAI，等待保存完成。无需另填客户端参数，也不需要再点一次保存。
5. 点击已添加服务的卡片主体打开详情，确认**已连接**，查看**工具**列表。工具较多时，在列表内向下滚动会继续加载。
6. 按[选择角色工具](./agent-tools.md#选择角色工具)完成配置，再让智能体执行任务。

新建的浏览器授权预设在授权成功后才保存；授权期间点击**取消**或关闭 ModxAI 的授权弹窗，不会完成添加。仅关闭浏览器标签不会等同于取消应用中的等待。

无需浏览器授权的预设会直接保存并尝试连接，例如 Context7 和本地 Playwright。保存成功不等于连接成功，请以详情中的状态和工具列表为准。

## 确认访问范围

- GitHub 快捷预设使用只读服务。按浏览器页面选择允许访问的仓库；组织仓库可能需要管理员批准。此入口不用于创建提交或修改仓库。
- 其他服务的访问范围由账号权限及授权页面决定；快捷添加不代表获得全部资源或免费额度。
- 未显示的服务只有在提供兼容 MCP 地址或本地启动方式时，才能尝试[自定义服务](./custom-service.md)。普通网页地址不能直接作为 MCP 连接地址。

## 授权未完成

| 现象 | 下一步 |
| --- | --- |
| 浏览器未打开，或授权页被关闭 | 在 ModxAI 授权弹窗中点击**重试**重新打开；若流程已经失败，重试会重新发起授权 |
| 授权被拒绝或已过期 | 重新发起授权，核对账号和允许的范围 |
| 提示仅支持本机后端 | 使用连接本机后端的桌面应用，不要通过关闭浏览器安全限制绕过 |
| 授权成功但保存失败 | 查看弹窗错误；先检查服务是否已出现，再决定是否重试，避免重复添加 |
| 保存后连接失败 | 点击服务卡片查看具体错误，按[管理与排错](./manage.md)处理 |

如果页面显示设备验证码，只在此次服务商授权页面按提示使用，不要发到聊天中。

## 取消授权

点击已添加的服务卡片，在详情底部点击**取消授权**并确认。此操作清除本机保存的授权并断开连接，保留服务配置和工具选择。

**服务商端的授权不会因此撤销。** 如需彻底撤销访问，还应到服务商账号设置中移除授权。需要重新使用时，保持服务开关开启，在详情底部点击**授权**，完成后等待保存和连接。
