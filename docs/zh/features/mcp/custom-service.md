# 自定义服务

> v1.1.12
> 2026-11

> 本指南对应待发布的 v1.1.12。

服务商提供 MCP 地址或本地程序启动说明时，可手动配置连接。填写 MCP 服务入口，不是服务商首页或普通 API 地址。

## 添加远程服务

1. 打开 **设置 → MCP → 自定义服务**，点击**添加**。
2. 填写**服务名称**，将**连接方式**设为**远程服务**。只有服务商明确要求旧版 SSE 时，才选择**远程服务（旧版 SSE）**。
3. 填写**服务地址**，按服务商说明选择**认证方式**：

   | 认证方式 | 填写内容 |
   | --- | --- |
   | 自动识别 | 由服务响应确定是否需要浏览器授权 |
   | 浏览器授权 | 保存后按提示在浏览器中授权 |
   | 访问令牌 | 将令牌填写到**访问令牌**字段 |
   | 自定义请求头 | 按服务商说明填写请求头名称和私密值 |
   | 无需认证 | 仅用于明确不需要认证的服务 |

4. 如服务需要额外请求头、公开 OAuth 客户端或超时设置，展开**高级设置**填写。
5. 可点击**测试连接**检查连接和工具发现。需要先授权的服务可能在测试中提示认证失败，此时先保存并完成授权。
6. 点击**保存**。手动选择**浏览器授权**的新服务会接着打开授权流程；其他需要授权的服务可在卡片上点击**重连**，或在详情中点击**授权**。
7. 确认状态为**已连接**，再打开**详情**检查工具目录。

请从服务商官方接入说明复制地址。令牌和密钥应填入私密字段，不要放入聊天、服务名称或 URL。

## 本地程序

本地 MCP 服务运行在**后端电脑**上。先按服务提供方的说明准备可执行程序及所需环境，再填写连接配置。不要把第三方依赖安装进 ModxAI 自身的运行环境。

1. 在**自定义服务**中点击**添加**，选择**本地程序**。
2. 填写**服务名称**和**程序**。程序可以是可执行文件名称或完整路径；无法定位程序时优先使用完整路径。
3. 在**启动参数**中逐项添加参数，每个参数独占一行。不要把整段终端命令填进**程序**。
4. 按需在**高级设置**中填写**工作目录（可选，绝对路径）**和**环境变量**。
5. 点击**测试连接**，检查返回的工具数量；需要中止时点击**取消测试**。
6. 点击**保存**，确认服务显示**已连接**，并查看工具目录。

例如，已有一份可信的 Python MCP 服务时，**程序**填写该服务独立环境的 Python 路径，**启动参数**第一行填写脚本完整路径。不要使用 ModxAI 应用本身作为 Python 解释器。

**测试或启用服务会启动程序。** `npx`、`uvx` 等启动方式还可能下载并执行代码；使用前核对来源、版本和安装要求。注册服务不会替您安装缺失依赖。

## 测试与保存的区别

- **测试连接**只检查连接并发现工具，不调用业务工具，也不保存本次修改。本地测试可能启动临时进程。
- **保存**会保存连接配置并尝试连接，不代表每个工具都可成功执行。
- **已连接**后仍需[为角色选择工具](./agent-tools.md#选择角色工具)。

## 高级设置与凭据修改

| 设置 | 用法 |
| --- | --- |
| 连接超时 | 等待连接的时限，5～120 秒；自定义服务默认 20 秒 |
| 调用超时 | 等待单次工具调用的时限，5～1800 秒；默认 120 秒 |
| 授权服务器、公开客户端 ID | 仅在服务商要求时填写，不要填入客户端密钥 |
| 请求头、环境变量 | 名称按服务要求填写，值通过私密字段输入 |

编辑已有服务时：

- 令牌留空会保留原值；需要移除时勾选**清除已保存令牌**。
- 请求头和环境变量保留已有值，除非勾选**替换原值**或移除条目。勾选替换后留空会保存空字符串，并非保留原值。
- 配置被其他操作修改后，可点击**载入最新配置（替换未保存的修改）**，核对后再编辑。
- 修改共用服务会影响其他会话。变更地址或认证方式后，重新确认连接和权限，不要直接假定旧授权仍可用。
