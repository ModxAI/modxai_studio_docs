# 自定义服务

> v1.1.12
> 2026-11

服务商提供 MCP 地址或本地程序启动说明时，可手动配置连接。请使用官方接入说明，不要把服务商首页或普通 API 地址当作 MCP 地址。

## 添加远程服务

1. 打开 **设置 → MCP**，在**自定义服务**右侧点击**添加**。
2. 填写**服务名称**，把**连接方式**改为**远程服务**；服务商明确要求旧版 SSE 时，选择**远程服务 (旧版 SSE)**。
3. 填写**服务地址**，按接入说明选择**认证方式**：

   | 认证方式 | 操作 |
   | --- | --- |
   | 自动识别 | 先保存；连接提示需要认证时，再完成授权 |
   | 浏览器授权 | 新服务保存后会打开授权流程，按提示完成 |
   | 访问令牌 | 在出现的**访问令牌**输入框填写令牌 |
   | 自定义请求头 | 点击**添加条目**，填写请求头的**名称**和**私密值** |
   | 无需认证 | 用于服务商明确说明不需要认证的连接 |

4. 按需展开**高级设置**，填写额外请求头或调整超时。授权服务器和公开客户端 ID 只在服务商明确要求时填写，不要填入客户端密钥。
5. 可点击抽屉底部左侧的**测试连接**；结果显示在底部。需要中止时点击**取消测试**。
6. 点击右下角**保存**。新服务选择了**浏览器授权**时，接着完成弹出的授权流程。使用**自动识别**或编辑已有服务后，如需授权，点击服务卡片进入详情，再点**授权**。
7. 在详情中确认**已连接**，查看**工具**列表。

测试不代替账号授权。若测试提示需要认证，先保存服务，再完成授权。令牌和密钥只填写在私密字段，不放入聊天、服务名称或 URL。

## 本地程序

本地程序运行在提供 ModxAI 服务的电脑上，而不是任意一台打开界面的电脑。先按服务说明准备程序和所需环境；不要把第三方依赖安装进 ModxAI 自身的运行环境。

1. 在**自定义服务**中点击**添加**，将**连接方式**保持为**本地程序**。
2. 填写**服务名称**和**程序**。程序可填可执行文件名称或完整路径；也可用右侧文件夹按钮选择文件。
3. 在**启动参数**下点击**添加参数**，逐项填写，每个输入框一个参数。不要把整条终端命令放进**程序**。
4. 按需展开**高级设置**，填写**工作目录**，或在**环境变量**中点击**添加条目**，填写名称和私密值。
5. 点击**测试连接**，检查是否连接成功并发现工具；测试通过后点击**保存**。
6. 点击保存后的服务卡片，在详情中确认连接状态和工具列表。

例如，已有一份可信的 Python MCP 脚本时，**程序**填写该脚本独立环境的 Python 路径，点击**添加参数**填写脚本的完整路径。连接局域网后端时，所填路径必须在后端电脑上有效。

**测试或启动服务会执行程序。** `npx`、`uvx` 等启动方式可能下载并执行代码。请核对来源、版本和安装要求；缺少 Node.js、Python 等环境时，需要先按服务说明准备，ModxAI 不提供 MCP 专用安装向导。

## 测试与保存的区别

- **测试连接**检查连接和工具发现，不调用业务工具，也不保存修改。本地测试可能启动临时进程。
- **保存**记录配置；启用的服务会尝试连接，关闭的服务仍保持关闭。
- **已连接**不表示每个工具都有资源访问权限；还需[为角色选择工具](./agent-tools.md#选择角色工具)。

## 高级设置与凭据修改

连接超时默认 **20 秒**，可设为 5～120 秒；调用超时默认 **120 秒**，可设为 5～1800 秒。快捷预设可能使用不同的连接超时。

修改已有服务时，点击卡片上的铅笔图标（**编辑**）：

- **访问令牌**留空保留原值；填写新令牌后保存即可替换。移除时勾选**清除已保存令牌**。
- 已保存的请求头和环境变量不显示原私密值。不改动输入框会保留原值；输入新值后随保存替换。输入后再清空，会保存空字符串。删除条目请点击该行的移除图标，再保存。
- 若不想提交刚输入的值，点击**取消**后重新打开编辑，不要通过清空输入框来恢复原值。
- 地址中的查询参数值可能被隐藏。不修改地址会保留原值；需要修改时，重新填写完整地址及全部参数值。
- 出现配置冲突时，点击**载入最新配置（替换未保存的修改）**，重新核对后编辑。该操作会替换当前未保存的内容。

修改共用服务会影响其他会话。变更地址或认证方式后，请重新检查连接和授权。
