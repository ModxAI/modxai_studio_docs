# MCP 外部工具

> v1.1.12
> 2026-11

MCP 用于把外部服务的工具接入智能体，例如读取项目资料、查询在线文档，或调用本地程序。

入口：**设置 → MCP**。

## 开始使用

1. 在**快捷添加**中搜索服务，点击卡片或右侧 **＋** 添加；没有对应预设时，在**自定义服务**中点击**添加**。
2. 按服务要求完成浏览器授权，或填写连接信息后保存。
3. 点击已添加的服务卡片主体打开详情，确认状态为**已连接**，并能看到所需工具。
4. 回到智能体的**运行配置**，为角色选择工具，再发送任务。具体步骤见[在智能体中使用](./agent-tools.md)。

**连接服务后，还要为角色选择工具。** 账号授权决定可以访问哪些外部资源，角色的工具选择决定智能体可以调用哪些工具，任务中的审批则用于确认具体操作。

## 选择接入方式

| 您的情况 | 操作指南 |
| --- | --- |
| 在快捷添加中找到了服务 | [快捷添加与授权](./connect.md) |
| 已有 MCP 地址、令牌或本地程序启动说明 | [自定义服务](./custom-service.md) |
| 需要让智能体使用工具，或协助配置服务 | [在智能体中使用](./agent-tools.md) |
| 需要修改连接、取消授权或排查错误 | [管理与排错](./manage.md) |

## 使用前注意

- 只连接可信服务。调用远程工具时，任务参数可能发送给服务商；账号权限、套餐和费用由服务商决定。
- 本地程序运行在提供 ModxAI 服务的电脑上，以下称为**后端电脑**。通常就是安装并运行 ModxAI 的电脑；连接局域网后端时，可能不是当前打开界面的电脑。
- 测试或启动本地服务会执行该程序，不代表它经过安全审查或在隔离环境运行。
- 浏览器授权须使用连接本机后端的桌面应用。
- 服务配置由连接同一后端的会话共用。修改、关闭或删除前，请留意其他会话是否仍在使用。

MCP 是让智能体调用外部工具；[外部访问](../gateway/overview.md)则是让外部应用调用 ModxAI。两者的连接方式和凭据不同。
