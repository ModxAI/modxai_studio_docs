# MCP 外部工具

> v1.1.12
> 2026-11

MCP 用于把外部服务的工具接入智能体。例如，读取已授权的项目资料，或调用您配置的本地程序。接入后，还需为角色选择允许使用的工具。

入口：**设置 → MCP**。

## 开始使用

1. 在**快捷添加**中选择服务；没有对应预设时，添加**自定义服务**。
2. 按服务要求完成浏览器授权或填写连接信息。
3. 确认服务显示**已连接**，打开**详情**检查工具目录。
4. 回到智能体的**运行配置**，为主角色或委派角色选择需要的 MCP 工具，再发送任务。

**已连接不等于智能体已获准使用。** 服务连接、角色的工具选择、任务中的操作审批是不同步骤。

## 选择接入方式

| 您的情况 | 操作指南 |
| --- | --- |
| 页面已有服务卡片，希望用账号授权连接 | [快捷添加与授权](./connect.md) |
| 服务商提供 MCP 地址、令牌，或本地程序的启动说明 | [自定义服务](./custom-service.md) |
| 已连接服务，需要让智能体调用工具或协助接入 | [在智能体中使用](./agent-tools.md) |
| 需要重连、修改配置、取消授权或排查失败 | [管理与排错](./manage.md) |

## 使用前注意

- 远程服务需要联网，账号权限、套餐和费用由服务商决定。快捷添加不代表免注册、免费或获得全部账号权限。
- MCP 调用可能把任务参数发送给外部服务。仅连接可信服务，并只选择任务需要的工具。
- 本地程序在**后端所在电脑**运行，不一定是当前打开界面的电脑。测试或启用服务会启动该程序，不是隔离执行或安全审查。
- 浏览器授权目前仅适用于连接本机后端的桌面应用。
- 服务配置由使用同一后端的会话共用。修改或删除前，留意其他会话是否仍在使用。

MCP 是让智能体调用外部工具；[外部访问](../gateway/overview.md)则是让外部应用调用 ModxAI。两者的连接方式和凭据不同。
