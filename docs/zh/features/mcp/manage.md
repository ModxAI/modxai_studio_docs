# 管理与排错

> v1.1.12
> 2026-11

入口：**设置 → MCP**。点击已添加的服务卡片主体打开详情，查看连接状态、错误和工具列表。卡片左侧色条提示状态，悬停卡片可查看状态文字。

## 日常管理

| 入口 | 操作与结果 |
| --- | --- |
| 快捷添加右上角的刷新图标 | 刷新全部已启用服务的连接和工具目录；关闭的服务不会启动 |
| 已添加卡片的圆形箭头（**重连**） | 重新连接这一项；缺少浏览器授权时进入授权流程。服务关闭时需先打开开关 |
| 卡片的铅笔图标（**编辑**） | 修改连接信息，点击保存后生效 |
| 卡片的开关（**关闭 / 启动**） | 停用或启用服务，不删除配置和原工具选择 |
| 点击卡片主体 | 打开详情，查看状态、错误和工具；列表向下滚动会继续加载，**连接信息**可展开查看 |
| 详情底部的**授权 / 取消授权** | 完成浏览器授权，或清除本机授权；取消授权需确认，不撤销服务商端授权 |
| 详情底部的**删除** | 确认后删除连接配置和工具目录，所有会话将无法再调用此连接；历史消息和文件保留 |

删除快捷预设的连接后，快捷卡片恢复为可添加，不会移除预设入口。重新添加后，需要重新选择角色工具。

应用启动时会刷新一次已启用服务，之后不按固定间隔刷新目录，也不持续自动重试失败连接。网络恢复后可手动重连；只切换页面不会重新连接全部服务。

若旧本地预设失败，详情可能显示**更新并连接**。它会按预设更新启动参数、补齐缺少的默认环境变量，并在需要时延长连接超时，然后重试。普通卡片的**重连**不会替换这些参数。

## 理解状态

| 状态 | 下一步 |
| --- | --- |
| 已禁用 | 需要使用时打开卡片开关 |
| 待连接 / 连接中 | 等待连接结果；长时间未完成时检查配置和错误 |
| 已连接 | 查看工具列表并配置角色；不代表业务任务已经完成 |
| 需要认证 | 按详情提示授权，或编辑服务补齐凭据 |
| 连接失败 | 查看详情中的具体错误，修正后重连 |
| 正在停止 | 等待停止完成 |

目录刷新失败会保留上次完整目录，因此还能看见工具不代表当前连接正常。工具标注不支持的 Schema 或外部引用时，不能直接用于任务。

## 常见问题

### 找不到程序或工作目录

检查运行 ModxAI 服务的电脑是否安装了所需程序、目录是否存在。可把**程序**改为完整路径。连接局域网后端时，当前电脑的文件路径不能直接当作后端路径。

### 连接超时或连接失败

本地服务检查程序、启动参数和依赖；远程服务检查 MCP 地址、网络和认证方式。确实需要更长等待时间时，在编辑的**高级设置**中调整**连接超时**。

### 认证失败、缺少凭据或拒绝访问

点击卡片上的**编辑**补齐令牌或请求头；使用浏览器授权的服务，在详情中完成授权。还需确认账号有目标工作区、项目或仓库的权限。组织资源可能需要管理员批准。

### 连接正常，但智能体找不到工具

1. 点击服务卡片，确认工具列表中存在目标工具且未标为不支持。
2. 在当前会话的角色配置中检查**启用工具**和工具选择，改选后点击**确定**。
3. 委派角色还需检查主角色是否也允许使用这些工具。
4. 通过智能体接入时，检查结果是否只保存了服务或未自动启用工具；补选后再发一个简单任务。

不要反复添加同一个服务来解决工具未勾选的问题。

通过外部应用或 Bot 使用时，还要检查[外部访问](../gateway/overview.md)中的高风险工具限制；角色已勾选不代表能绕过该限制。

### 工具列表加载失败或目录无效

工具列表中的读取错误可点击该处的**重试**。若详情提示整个目录刷新失败，可先重连。目录超限或工具定义不受支持时，需要服务方提供兼容的目录，反复勾选工具不能解决。

### 提示后端依赖不完整

这与外部程序未安装不同：前者是 ModxAI 运行依赖问题，后者需要检查第三方服务自己的环境。保存错误提示，按应用安装说明检查；不要为此把第三方包混装进 ModxAI 环境。重启后仍有错误时，可携带脱敏后的提示反馈问题。

### 操作超时后，不确定是否执行成功

查看原调用结果，并到服务商端核实实际状态。尤其是创建、发送、修改和删除操作，未确认前不要再次执行。取消任务、关闭连接或取消本机授权，都不等于撤销已经发生的外部操作。
