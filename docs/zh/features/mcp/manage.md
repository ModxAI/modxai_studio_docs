# 管理与排错

> v1.1.12
> 2026-11

在 **设置 → MCP** 查看连接状态、重连服务或修改配置。先看卡片和**详情**中的错误，再选择对应操作。

## 日常管理

| 操作 | 作用 |
| --- | --- |
| 快捷添加右上角的**刷新** | 刷新已启用服务的连接和工具目录，不启动已禁用服务 |
| 服务卡片的**重连** | 重新连接该服务；缺少浏览器授权时接续授权流程 |
| **编辑** | 修改连接信息，保存后影响使用该服务的其他会话 |
| **关闭 / 启动**开关 | 停用或启用服务，不删除配置 |
| **详情** | 查看连接状态、工具说明和连接信息 |
| **取消授权** | 清除本机授权并断开连接，保留配置和工具选择；不撤销服务商端授权 |
| **删除** | 删除服务配置和工具目录，所有会话不再能调用此服务；历史消息和文件保留 |

应用启动时会刷新一次已启用服务。它不会按固定间隔自动刷新，也不会在失败后持续自动重试。网络恢复或服务变更后，可手动**刷新**或**重连**。

若旧预设连接失败且详情显示**更新并连接**，该操作会更新预设的连接默认值并重试；仍需检查连接结果。

## 理解状态

| 状态 | 含义及下一步 |
| --- | --- |
| 已禁用 | 服务已关闭，需要时用开关启动 |
| 待连接 / 连接中 | 尚未完成连接，等待结果或检查服务配置 |
| 已连接 | 连接已建立；继续检查工具目录及角色选择，不代表业务任务已完成 |
| 需要认证 | 补齐凭据或重新授权 |
| 连接失败 | 查看具体错误，修正后重连 |
| 正在停止 | 等待停止完成后再操作 |

目录刷新失败时会保留上次完整目录。**还能看到工具不代表当前连接可用**；应先处理连接或目录错误。标有不支持的 Schema 或外部引用的工具不能作为可用工具使用。

## 常见问题

### 找不到程序或工作目录

在后端电脑检查程序是否已安装、路径是否正确，以及指定目录是否存在。必要时把**程序**改为完整路径。当前电脑上的路径不一定在后端电脑上可用。

### 连接超时或连接失败

核对本地程序与参数，或远程 MCP 服务地址、网络和认证方式。仅当服务确实需要更长等待时间时，再调整**连接超时**。不要用增加超时掩盖地址或权限错误。

### 认证失败、缺少凭据或拒绝访问

在**编辑**中补齐令牌或请求头，或重新浏览器授权。检查账号是否有目标工作区、项目或仓库的权限；组织资源可能需要管理员批准。相关流程见[快捷添加与授权](./connect.md)。

### 连接正常，但智能体找不到工具

依次检查：

1. **详情**中是否已取得工具目录，目标工具是否受支持。
2. 主角色或委派角色是否开启**启用工具**并选择了目标工具。
3. 您修改的是否为当前任务使用的角色和配置。
4. 若刚通过智能体注册并授权工具，是否已进入后续模型请求。

不要反复添加同一个服务来解决角色未选工具的问题。

### 目录无效、目录超限或工具不受支持

先确认地址指向 MCP 服务，并核对服务版本和接入方式。目录超限或不支持的工具定义不能靠勾选角色工具解决；需要服务方提供受支持的目录。修改后再刷新。

### 后端依赖不完整

按提示修复 ModxAI 运行环境。不要把“后端依赖不完整”与“找不到外部程序”混为一谈：前者是应用运行依赖，后者需检查外部服务自己的环境。遇到进程监护未就绪的提示，可先重启后端。

### 操作超时后，不确定是否执行成功

读取原工具调用或注册操作的结果，并到服务商端检查实际状态。尤其是创建、发送、修改和删除操作，未确认前不要重复执行。取消任务或停止连接也不等于撤销外部已发生的操作。
