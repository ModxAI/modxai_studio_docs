# 常见问题

> v1.1.11
> 2026-11

本文汇总了 ModxAI Studio 使用过程中的常见问题和解决方案。

---

## 快速入门

### 首次启动后应该做什么？

1. 打开**模型中心**，从**模型下载**下载聊天模型，或在模型页面导入本地模型。
2. 加载模型后，打开**智能体 → 聊天**，发送第一条消息。
3. 如需训练、数据处理等功能，先在**设置 → 系统**安装所需环境。完整步骤见[快速开始](./getting-started/quick-start.md)。

### 哪些功能需要在设置下载环境？

| 功能 | 环境要求 |
|------|---------|
| 文本对话（llama.cpp） | **无需** |
| 文本对话（HF Transformers） | **需要** CPU 或 GPU 环境 |
| 多模态对话 | **无需**（使用 llama.cpp） |
| 向量模型/重排模型 | **需要** CPU 或 GPU 环境 |
| SD 图像生成 | **需要** CPU 或 GPU 环境 |
| TTS 语音合成 | **需要** CPU 或 GPU 环境（推荐 GPU） |
| STT 语音转文本 | **需要** CPU 或 GPU 环境（推荐 GPU） |
| 模型训练 | **需要** CPU 或 GPU 环境（推荐 GPU） |
| 智能体（浏览器/Web工具） | **需要** 安装「全部」或「智能体」能力 |
| 音频转文本 | **需要** CPU 或 GPU 环境（推荐 GPU） |

## 模型管理

### 模型下载很慢怎么办？

- **切换下载源**：中国内地用户建议使用 ModelScope，海外用户使用 Hugging Face
- **检查网络**：确保网络连接稳定
- **分批下载**：大模型可选择部分量化版本先下载

### 导入模型后不显示？

- 点击**刷新按钮**更新模型列表
- 检查文件格式是否正确：
  - 聊天模型：`.gguf` 或 `.bin`，或包含 `.safetensors` 的 HF 模型目录
  - 多模态模型：`.gguf` 或 `.bin`
  - 向量/重排模型：`.safetensors`（需导入目录）

### 模型加载失败？

常见原因及解决方案：

| 原因 | 解决方案 |
|------|---------|
| 内存不足 | 关闭其他应用，或选择更小的量化版本（Q2_K、Q3_K_S） |
| 环境未安装 | 向量/重排/SD 模型需先在**设置**中安装环境 |
| 文件损坏 | 重新下载模型文件 |
| 格式不支持 | 确认文件格式符合要求 |

### LoRA 不兼容怎么办？

LoRA 必须与基础模型架构匹配。请确保：
- LoRA 是针对该基础模型训练的
- LoRA 格式正确（聊天模型使用 `.gguf` 格式的 LoRA）

### 同一时间能加载多少模型？

- **同类模型**：同一分类只能加载一个基础模型
- **不同类模型**：聊天、向量、重排、SD、TTS、STT 可同时加载
- **特别限制**：聊天和多模态不能同时加载

### HF Transformers 模型和 GGUF 模型有什么区别？

| 对比 | GGUF（llama.cpp） | HF Transformers |
|------|-------------------|-----------------|
| 环境要求 | 无需安装 | 需安装环境 |
| 推理速度 | 快 | 取决于设备 |
| 精度控制 | 量化版本固定 | 可灵活选择 float16/32 |
| 多模态 | 支持 | 不支持（仅文本） |

### 如何让其他应用调用我已加载的模型？

加载模型后，ModxAI Studio 自动提供 OpenAI 兼容的 HTTP API（`/v1/chat/completions`）。同一局域网内的其他设备或应用可直接调用。详见 [模型库 - 局域网推理服务](./features/models/overview.md#局域网推理服务)。

### 多模态模型能同时使用知识库（RAG）吗？

不能。多模态对话模式下 RAG 检索功能不可用。如需知识库问答，请切换到纯文本聊天模型。

## 智能体

### 智能体需要什么前置条件？

1. 打开**智能体工作台**，在会话配置中为主角色选择模型。本地、在线或局域网模型均可，见[角色配置](./features/agent/roles.md)。
2. 需要浏览器或网页搜索时，在**设置**中安装「全部」或「智能体」环境。
3. 新建会话，输入任务并发送。

### 智能体适合多大的模型？

优先选择擅长指令理解和工具调用的模型，并根据内存、显存和任务复杂度调整。先用简单任务确认效果，不要只按参数量判断。选型建议见[模型要求](./features/agent/overview.md#模型要求)。

### 智能体能做什么？

- 自动搜索互联网获取信息
- 浏览和提取网页内容
- 读写本地文件
- 执行终端命令
- 管理任务清单并追踪进度
- 记住偏好

<a id="网页搜索没有用上新的结果"></a>

### 网页搜索不可用怎么办？

请先检查网络和代理，再到**设置 → 系统 → 环境配置**确认已安装智能体环境；必要时使用**重装**。也可检查当前选择的搜索来源，见[高级参数](./features/agent/advanced-settings.md)。

### 智能体的数据安全吗？

使用智能体前，请检查工作区、工具权限和审批设置。在线模型和联网工具可能向对应服务发送任务内容，请按服务条款判断是否适合处理敏感数据。对重要文件操作保留人工审批，并检查执行结果。

## AI 对话

### 对话没有响应？

1. 确认模型已成功加载（状态显示"已加载"）
2. 打开**模型中心**，查看页面右上角的 CPU、内存和显存使用率
3. 尝试新建对话重试

### AI 回复为空或显示"模型未返回有效回复"？

建议：
- 重新表述问题，使描述更清晰
- 检查推理参数是否合理（温度不宜过高）
- 确认模型文件完整

### 多模态对话不显示附件按钮？

必须加载**多模态模型**才能使用图文对话功能。普通聊天模型不支持图片输入。

### 开启 RAG 推理后提示无法使用？

使用 RAG 功能前需要：
1. 先在**数据处理**模块创建 RAG 知识库
2. 在推理参数中选择知识库
3. 建议加载向量模型以及同时加载重排模型,但要注意资源占用.

### 图片格式限制？

- **支持**：JPG、PNG
- **不支持**：GIF、BMP、WebP 等格式

## 数据处理

### 处理过程可以切换页面吗？

可以。处理任务在后台运行，切换页面不影响进度。返回后可在"进度监控"查看状态。

### AI 节点处理很慢怎么办？

AI 节点需要调用模型推理，速度取决于硬件配置：
- 使用较小的模型进行处理
- 确保 GPU 可用以加速推理
- 先用少量数据测试效果

### 断点续跑如何操作？

以下操作适用于 SFT 和 RAG 的文本、代码处理流程：

1. 取消勾选已完成的步骤
2. 保留需要重新执行的步骤
3. 确保前置步骤的输出数据存在

音频转文本不能从中断点继续；重新开始会从头转录，并可能覆盖同名结果。请按[音频转文本](./features/dataset/audio2text.md)检查输入和输出目录。

### 什么是结构化数据输入？

在 SFT 或 RAG 数据处理中，文件类型选择「JSON」即可进入结构化数据模式。适合已有固定字段的 JSON/JSONL 数据（如新闻、业务记录），可直接将字段映射到标准格式，无需走非结构化清洗链路。

### 导出格式 sft_chatml / pretrain / dpo 有什么区别？

| 导出格式 | 样本内容 | 适用场景 |
|----------|----------|----------|
| sft_chatml | system/user/assistant 对话格式 | SFT 微调训练 |
| pretrain | 文本语料 | 分词后用于预训练 / 继续预训练 |
| dpo | prompt/chosen/rejected 偏好对 | 导出偏好样本；当前训练页面不支持 DPO |

非结构化文本、代码在 AI 合成步骤选择「导出格式」；结构化 JSON 在页面选择「训练格式」。SFT 和预训练优先使用输出的 `train/final_dataset.jsonl` 训练，不要将原始样本文件直接当作已分词训练文件。实际产物及用途见[SFT 数据处理](./features/dataset/sft.md)。

### 思维链模式（CoT）是什么？

开启后系统会自动注入推理型提示，引导模型输出思考过程。适合需要保留推理过程的数据.

## 模型训练

### 训练需要什么配置？

内存和显存需求取决于模型、序列长度、批大小、优化器以及是否使用 LoRA，不能只按参数规模确定。选择可用设备和匹配的环境，先用少量数据检查流程；内存或显存不足时，可尝试减小批大小或序列长度。准备步骤见[训练准备](./features/training/prepare.md)。

### "训练模型目录"填什么？

选择完整的本地 **Hugging Face 模型目录**，包含模型配置、权重和可用的 tokenizer 文件。权重可以是受支持的 Safetensors 或 PyTorch 格式，不要求文件固定叫 `model.safetensors`；这里不能使用 GGUF 推理模型。

### 评估支持哪些基准？可以用自己的问题吗？

评估页面提供 IFEval、MMLU-Pro、GSM8K 和 HellaSwag 四个固定基准，没有自定义样本文件入口。用自己的问题检查回答效果时，请打开[模型测试](./features/training/test.md)；基准准备与评分说明见[模型评估](./features/training/evaluate.md)。

### 训练中断后如何恢复？

在训练准备页面，设置"恢复训练检查点路径"为上次保存的检查点目录。

## SD 图像生成

### 生成按钮点击没反应？

检查：
1. 是否已加载 SD 模型
2. 提示词是否为空
3. 是否有正在进行的生成任务

### 生成质量不理想？

尝试以下调整：
- 增加采样步数（推荐 30-50）
- 调整 CFG 强度（推荐 7-12）
- 使用更详细的提示词
- 添加负向提示词排除不想要的元素

### 图生图效果与原图差异太大？

降低**变化强度（Strength）**参数，推荐 0.3-0.6。

### 视频生成失败或卡住？

- 降低视频帧数（推荐 20-40 帧）
- 降低分辨率（推荐 512×512）
- 检查显存是否充足

### 资源占用建议

| 显存 | 推荐设置 |
|------|---------|
| 4GB | 512×512，步数 20-30 |
| 8GB | 768×768，步数 30-50 |
| 12GB+ | 1024×1024，步数 50+ |

## TTS 语音合成

### TTS 功能不可用？

检查以下几点：
1. 是否已在设置中安装环境
2. 环境安装后是否刷新了状态
3. TTS 能力是否显示为可用
4. 是否已加载 TTS 模型

### TTS 依赖安装很慢？

- misaki 库使用 PyPI 官方源安装，国内网络可能较慢
- 安装过程中请保持网络稳定
- 若超时失败，可通过重新安装环境重试

### TTS 能力显示不可用？

- TTS 依赖的 spaCy 模型是异步下载的，可能延迟数十秒至数分钟
- 主环境安装完成后，请稍等并刷新环境状态
- 若仍不可用，尝试重启应用或修复安装

### 生成的语音不自然？

- 检查输入文本是否有语法错误
- 尝试不同的音色预设
- 调整语速参数
- 确保语言设置与文本内容匹配

### TTS 只支持中英文？

是的，当前版本仅支持中文和英文。日语等其他语言需要额外依赖库，暂未内置。

### TTS 推理失败？

- 部分 AMD CPU 可能存在兼容性问题
- 建议使用 NVIDIA GPU 环境
- 检查模型是否正确加载

## 环境配置

### 首次启动的环境引导关掉了，在哪里重装？

打开**设置 → 系统 → 环境配置**。可以选择「全部」「智能体」或「语音合成」。已经安装过时，使用**重装**。

### 环境安装失败？

常见解决方案：
- **切换镜像源**：中国内地用户选择阿里云或腾讯云
- **检查磁盘空间**：根据所选环境检查[空间要求](./features/settings/environment.md#存储位置与空间要求)。
- **检查网络**：确保能访问下载源
- **重试安装**：点击"重装"按钮

### CPU 和 GPU 环境选哪个？

- **有 NVIDIA 显卡**：选择 GPU 环境，推理和训练速度大幅提升
- **无独立显卡**：选择 CPU 环境，也可正常使用大部分功能

### 全部 / 智能体 / 语音合成 三种安装能力有什么区别？

| 安装能力 | 包含内容 | 适用场景 |
|----------|----------|----------|
| 全部 | 训练 + 智能体 + TTS 全部依赖 | 需要使用所有功能 |
| 智能体 | 核心库 + 浏览器环境 | 仅需智能体的网页和 Web 工具 |
| 语音合成 | 基础库 + TTS 依赖 | 仅需语音合成功能 |

### 智能体的浏览器工具无法使用？

需要安装「全部」或「智能体」安装能力。仅安装「语音合成」能力时，智能体的浏览器和 Web 工具不可用。

### TTS 安装后仍不可用？

在「全部」模式下，TTS 依赖为异步下载，完成后需等待一段时间再刷新环境状态。若异步下载失败，可切换到「语音合成」模式独立重装（同步下载）。

### 环境安装后需要重启吗？

不需要。安装完成后相关功能立即可用。但对于 TTS 异步安装，根据网络情况可能需要等待数分钟后刷新确认。

## MCP 外部工具（v1.1.12）

以下内容适用于待发布的 v1.1.12。

### MCP 已连接，为什么智能体还不能用？

连接只建立服务通道。还需在主角色或委派角色中开启工具并选择需要的 MCP 工具；账号也必须有目标资源的权限。见[选择角色工具](./features/mcp/agent-tools.md#选择角色工具)。

### 取消授权会撤销服务商端的访问吗？

不会。此操作只清除本机授权并断开连接，保留配置与工具选择。要撤销服务商端的访问，还需在服务商账号设置中移除授权。见[快捷添加与授权](./features/mcp/connect.md#取消授权)。

### MCP 连接失败应该先查什么？

先看服务卡片和详情中的错误：本地程序检查后端电脑上的程序与目录，远程服务检查 MCP 地址、网络和认证。测试连接不等于业务工具调用成功。见[管理与排错](./features/mcp/manage.md)。

## 其他问题

### 数据存储在哪里？

- **模型文件**：保存在您指定的目录
- **对话记录**：存储在应用本地数据库
- **生成图片**：默认在系统临时目录，可在参数中指定保存位置

> 卸载应用不会删除本地数据库和模型文件。

### 如何完全清除数据？

需要手动删除：
- 模型文件目录
- 应用数据目录（C:\Users\<用户名>\AppData\Local\ModxAI）

### 如何反馈问题？

- **应用内反馈**：设置 → 帮助与反馈 → 提交反馈
- **邮箱**：support@modyu.tech
