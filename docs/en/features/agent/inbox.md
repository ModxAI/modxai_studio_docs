# Inbox

The Inbox collects notifications from agents and scheduled tasks. Use it to return to a result, reply, or review an approval request.

1. Select the **Inbox** icon. The badge shows unread task notifications.
2. Browse messages by date, or narrow the list with **Search conversations or tasks** and **Unread Only**.
3. Select a message to open its conversation or run record. For a pending approval, review the actual request in the original conversation.
4. **Mark All as Read** only updates read status. **Clear Read Messages** removes read notifications from the Inbox. Neither action deletes the underlying conversations or task records.
